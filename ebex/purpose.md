# EBE Purpose（開発用ダミー）

1. 特定フォルダ内のファイルを入力に AI スキルを発火し、出力を同フォルダに置く
2. 入力と出力を同一プロジェクトフォルダで完結させ、コンテキストを散逸させない
3. ファイルツリー・エディタ・Agent を 1 画面で操作できる 3 ペインワークスペースを提供する
4. 外部 IDE やエディタでの変更を mtime 同期で自動反映する
5. 編集中の未保存内容は外部変更で上書きしない
6. Agent セッションはプロジェクトフォルダ単位の `session.json` で永続化する
7. `@` 参照は当該フォルダ内のファイルに限定し、必要に応じてフォルダ外も参照できる
8. 多拡張子プレビュー（md, html, csv, json, yml, vtt）で成果物をその場で確認する
9. EBE Purpose（本ドキュメント）を常に参照可能にし、作業の目的を忘れない
10. v1 は 1 階層のフラットファイルにスコープを限定し、複雑性より速度を優先する
