# 自分専用の提案スキルを作る

## 変えたいこと
- 社内の課題を解決する３ペインワークスペースを作った
- 簡易版クロードコードのようなツール
- このツールを部に導入したい
- 導入にあたり AI ライセンスの承認をもらいたい

##社内の課題とは
- 社内で便利な AI スキルをたくさん作っている
- しかし AI スキルの配布方法に頭を悩ませている
- 実行には VSCode + GitHub Copilot が必要だが導入が進んでいない
	- 理由１：社内のプロセスが非常に面倒で難しい
	- 理由２：個人ごとに課金され、申請が必要
- 社内で使える AI API キー
	- ベーシックプラン（無料）では GPT 5 nano など軽量モデルしか使えず、成果物の品質が悪い
	- チームプラン（月250€ + 超えた分は従量課金）を使って、Claude Sonnet や Opus を使いたい

## 権限を持つ人
- 課長
	- ドイツ人
	- AI やテクノロジーにとても詳しいが、コストには厳しい
	- 論理的に話さないと聞き入れてもらえない
	- まず課長を説得する必要がある
- 部長
	- 日本人
	- AI の推進に積極的だが、AI やテクノロジーには疎い
	- オープンマインドで和を大切にする人柄
	- 最終的な承認の権限を持つ
