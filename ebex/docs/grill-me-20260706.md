# EBEX — グリルセッション記録（3ペインワークスペース設計）

**実施日**: 2026-07-06  
**目的**: dx-training-studio をベースにした 3ペイン AI ワークスペース EBEX の機能・スコープ・実装方針を固める  
**前提**: ファイルは `ebex/` 配下に配置。入力・出力の正本は `ebex/workspace/` 内のプロジェクトフォルダ  
**ステータス**: 主要決定済み ✅ / 未決事項あり（後述）

---

## 背景

- EBEX は **特定フォルダ内のファイルを入力に AI スキルを発火し、出力結果を同フォルダに置く** だけのシンプルなツール。dx-training-studio の **引き算** でほぼ完成する想定。
- 配置先は `ebex/` フォルダ。Next.js + shadcn/ui ベース。
- dx-training-studio との主な差分:
  - 4ペイン → **3ペイン**（ファイルツリー / エディタ+プレビュー / Agent）
  - Series/Course/Lesson 階層 → **`ebex/workspace/<プロジェクトフォルダ>/` + 直下ファイル（1階層）**
  - 画像管理・曼陀羅・社内コンテキスト DB・Git diff 等は **対象外**
- Claude Code のような再帰ファイルツリーは技術的には可能だが、サブフォルダ CRUD・@ 参照・検索・DnD 等が横断的に複雑化するため **v1 は見送り**。

---

## 決まったこと

### 1. 全体構成・実装起点

| 項目                | 決定内容                                                              |
| ------------------- | --------------------------------------------------------------------- |
| **アプリ配置**      | `ebex/` 配下に standalone Next.js アプリ                              |
| **実装起点**        | **dx-training-studio を `ebex/` にコピーして引き算**（A）             |
| **ペイン構成**      | Pane 1: ファイルツリー / Pane 2: 編集+プレビュー / Pane 3: Agent のみ |
| **データ正本**      | `ebex/workspace/<プロジェクトフォルダ>/` 内のファイル                 |
| **Pane 1 表示深度** | プロジェクトフォルダ + **直下ファイル 1階層のみ**（v1）               |

流用候補: Workspace シェル、Pane リサイズ、Agent スタック、settings、CodeMirror、API パターン、mtime 同期（`useContentSync`）。  
削除候補: Series/Course/Lesson、画像管理、曼陀羅、社内コンテキスト、Git diff モード等。

### 2. Pane 1 — ファイルツリー

| 項目             | 決定内容                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| **ヘッダー**     | ツール名 **EBEX** を表示                                                                           |
| **表示対象**     | `ebex/workspace/` 直下の各プロジェクトフォルダと、その 1階層下のファイル                           |
| **検索**         | ペイン上部に検索ボックス。キーワードにマッチするフォルダ、または該当ファイルを含むフォルダだけ表示 |
| **フォルダ展開** | 展開すると直下ファイル一覧を表示                                                                   |

**フォルダ操作**

| 操作                 | 挙動                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| **追加**             | 下部「フォルダを追加」→ モーダル（キャンセル / 追加 / 自動入力）                                       |
| **追加時・自動入力** | `{YYYYMMDD}-untitled`。同名存在時は `{YYYYMMDD}-untitled-{3桁通し番号}`（例: `20260706-untitled-002`） |
| **追加時・手入力**   | ユーザが任意の名前を入力可能                                                                           |
| **編集（リネーム）** | フォルダ名右の編集ボタン → リネームモーダル（キャンセル / 保存 / 自動入力）                            |
| **編集時・自動入力** | AI がフォルダ内ファイルの中身からスラッグ（英小文字・数字・ハイフン）を決定 → `{YYYYMMDD}-{slug}`      |
| **編集時・手入力**   | ユーザが任意の名前を入力可能                                                                           |
| **削除**             | 削除ボタン（編集の左）。確認ダイアログあり。**直下にファイルが1つでもあれば削除不可**                  |

**ファイル操作**

| 操作     | 挙動                                                                   |
| -------- | ---------------------------------------------------------------------- |
| **表示** | ファイル名。右: リネーム、左: 削除                                     |
| **追加** | フォルダ展開時、一覧最下部に「ファイルを追加」ブロック。DnD でも追加可 |

**非表示・警告**

| 項目                     | 決定内容                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| **EBEX 管理ファイル**    | `session.json` 等は Pane 1 に **表示しない**（A）                                              |
| **`.ebexignore`**        | 除外パターン拡張のアイデアとして採用方向。v1 同梱範囲は未決                                    |
| **サブフォルダ（v1）**   | OS 等で作られたサブフォルダは **非表示**。検知時はプロジェクトフォルダ行に ⚠ 警告アイコン（B） |
| **サブフォルダ（将来）** | 再帰ツリー（Claude Code 方式）は v2 以降で検討可。v1 はサブフォルダ CRUD も非対応              |

### 3. Pane 2 — 編集・プレビュー

| 項目                     | 決定内容                                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| **UI 方式**              | **編集 / プレビュー切替**（A）。dx-training-studio の `PaneSegmentControl` パターンを流用 |
| **プレビュー対応拡張子** | md, html, csv, json, yml（+ **vtt** を v1 候補として推奨。文字起こしワークフロー向け）    |
| **その他ファイル**       | プレーンテキスト扱い。シンタックスハイライト不要。プレビュー = 編集画面と同じ             |
| **ヘッダー左**           | パンくず: `フォルダ名 > ファイル名`                                                       |
| **ヘッダー右**           | EBE Purpose（🍃 アイコン）→ 大きめモーダル / ⚙ 設定                                       |

プレビュー実装の目安（未実装・方針のみ）:

| 拡張子     | プレビュー                                             |
| ---------- | ------------------------------------------------------ |
| md         | react-markdown（既存流用）                             |
| html       | サンドボックス iframe                                  |
| csv        | 表表示                                                 |
| json / yml | 整形表示（パースエラー時はエラー表示）                 |
| vtt        | タイムスタンプ付き発話リスト（話者ラベルがあれば表示） |

追加候補（優先度低）: **srt**（vtt と同系）、**tsv**（csv と同処理）、**svg**（画像表示）。

### 4. Pane 3 — Agent

| 項目                 | 決定内容                                                              |
| -------------------- | --------------------------------------------------------------------- |
| **表示内容**         | Agent ビューのみ（dx-training-studio Pane4 の Agent 部分を流用）      |
| **ヘッダー**         | Pane 2 と同様（パンくず / EBE Purpose / ⚙）                           |
| **セッション永続化** | **プロジェクトフォルダ単位**の `session.json` をフォルダ内に保存（A） |

**入力スコープ**

| 項目             | 決定内容                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **既定**         | ユーザが特別指定しない限り、**選択中（開いている）プロジェクトフォルダ内**が対象                                                  |
| **ファイル選定** | フォルダ内の全ファイルを自動注入するわけではない。**どのファイルを使うかはスキル側で自由に定義**                                  |
| **スキル内 UI**  | 例: 「ファイルをリスト表示してユーザに選ばせる」→ フォルダ内ファイルをリスト表示（フォルダ外指定も可能）                          |
| **`@` 参照**     | オートコンプリートは **開いているフォルダ内のファイルのみ**。メニュー下部に **「フォルダ外を参照…」** で OS ファイルピッカー（B） |

**出力**

| 項目                 | 決定内容                                                                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **基本方針**         | **スキル次第**                                                                                                                                             |
| **ファイル出力**     | スキルがファイル出力を指示 → 同フォルダ内に直接書き込み                                                                                                    |
| **同名ファイル**     | ユーザ確認が必要。**確認要否の方針もスキル側で定義**する方向（合意）。デフォルト `confirm` 推奨案: frontmatter `on_conflict: confirm \| overwrite \| skip` |
| **チャットのみ出力** | ファイルは書かずチャット欄に表示。ユーザが **コピーボタン** や **エディタ上書きボタン** で Pane 2 に反映                                                   |

### 5. EBE Purpose

| 項目       | 決定内容                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| **内容**   | 部のパーパス **10箇条**                                                                                |
| **正本**   | `ebex/purpose.md`（A）                                                                                 |
| **表示**   | Pane 2/3 ヘッダーの 🍃「EBE Purpose」クリック → 大きめモーダルに Markdown レンダリング（読み取り専用） |
| **更新**   | IDE で編集。Git 管理                                                                                   |
| **開発用** | 公開できないため **ダミーの適当な 10箇条** を同梱                                                      |

### 6. 設定（⚙）

| 項目           | 決定内容                                                                            |
| -------------- | ----------------------------------------------------------------------------------- |
| **載せる項目** | テーマ / フォントサイズ / 横幅 / AI モデル / AI API キー **のみ**                   |
| **保存方式**   | dx-training-studio と同様 localStorage 想定（`workspace-settings.ts` パターン流用） |

### 7. ファイル同期

| 項目               | 決定内容                                                                         |
| ------------------ | -------------------------------------------------------------------------------- |
| **外部変更の検知** | **mtime ポーリング**で自動反映（A）。dx-training-studio の `useContentSync` 流用 |
| **編集中保護**     | 未保存の編集中ファイルは外部変更で上書きしない                                   |
