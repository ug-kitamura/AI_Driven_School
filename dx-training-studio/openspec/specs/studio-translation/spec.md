# studio-translation Specification

## Purpose

Studio の翻訳編集（日本語正本 → 英語派生）の正本。編集言語の状態・言語切替の設置場所・操作ボタン列の配置と表記・英語ビューの構成・翻訳 API（stateless / モデル設定準拠 / 契約注入）・en 本文の読み書き・翻訳が古いことの伝え方を定める。
## Requirements
### Requirement: 編集言語は Workspace が持つ1つの状態である

Studio の編集言語（`ja` / `en`）はワークスペースの単一の状態としなければならない（SHALL）。これは面ごとの設定ではなく**アプリのモード**である——レッスン選択時は本文エディタと鉛筆ダイアログの中身が同じ状態に連動しなければならない（SHALL）——本文とメタで別々の言語にはできない。

選択階層が変わっても編集言語は**保たれなければならない**（SHALL）——選択変更を理由に `ja` へ戻してはならない（SHALL NOT）。モードはヘッダーの切替ボタンの表記（「日本語ビューに戻る」）で常時視認できるため、持ち越しは意図として読める。切替時・選択変更時に未保存の入力があれば破棄する（既存メタビューの作法に従う）。

#### Scenario: レッスンの本文とメタが連動する

- **WHEN** レッスン選択中に言語切替で英語モードにする
- **THEN** ペイン3 のエディタは `contents.en.md` の内容になり、鉛筆ダイアログは英語フィールドの編集になる

#### Scenario: 選択が変わってもモードが保たれる

- **WHEN** 英語モードのまま別のレッスンを選択する
- **THEN** 編集言語は `en` のままで、ペイン2 は新しいレッスンの英語ビューを表示する

#### Scenario: ホームへ移ってもモードが保たれる

- **WHEN** 英語モードでツリーのホーム行を選択する
- **THEN** ホームの英語ビューが表示される

### Requirement: 英語ビューは翻訳対象フィールドだけを原文併記で編集する

英語ビューには翻訳対象フィールドだけを表示しなければならない（SHALL）。表示順とラベルは次のとおりとする（SHALL）——順序は日本語ビューの並びに揃える:

| 階層 | 表示順とラベル |
|---|---|
| 全体（ホーム） | `Name` → `Description` |
| シリーズ | `Series name` → `Description` → `Catch` |
| コース | `Course name` → `Description` → `Catch` → `Target` |
| レッスン（モーダル） | `Lesson name` → `Description` → `Author` |

各入力には対応する日本語原文（名前はフォルダ名）を `原文: <値>` の形式で読取専用で併記しなければならない（SHALL）——`Author` も同じ形式に揃える（SHALL）。`Author` は原文併記の直下に**「著者名は自動翻訳出来ません」**の注記を表示しなければならない（SHALL）——翻訳ボタンが `author_en` を埋めないのは仕様であり、故障と誤読させない。slug・style・順序・リンク類は英語ビューに表示してはならない（SHALL NOT）。

英語ビューの「原文から翻訳」ボタンは AI 翻訳でフィールド値を埋める（SHALL）。`author_en` は翻訳ボタンの対象にしてはならない（SHALL NOT）——手編集のみ。保存は人が保存操作で実行する（SHALL）——翻訳ボタン自体は正本に書かない。英語フィールドの保存は `_en` フィールドと `en_source_hash` **だけ**に触れる専用経路で行い、日本語側のフィールドを書き換えてはならない（SHALL NOT）。

#### Scenario: コースの英語ビュー

- **WHEN** コースメタビューを英語ビューに切り替える
- **THEN** `Course name` → `Description` → `Catch` → `Target` の順に4入力と日本語原文の併記だけが表示される

#### Scenario: Author の原文併記と注記

- **WHEN** レッスンの英語モーダルを開く
- **THEN** `Author` のラベルの下に日本語の `author` が `原文: <値>` の形式で表示される
- **AND** その直下に「著者名は自動翻訳出来ません」の注記が表示される

#### Scenario: 翻訳ボタンは埋めるだけ

- **WHEN** 英語ビューで「原文から翻訳」を実行する
- **THEN** フィールドに訳文が入るが、保存するまで `.meta.json` は変わらない

#### Scenario: author_en は自動翻訳されない

- **WHEN** レッスンの英語ビューで翻訳ボタンを実行する
- **THEN** `name_en` / `description_en` は埋まるが `author_en` は変わらない

### Requirement: en 本文の読み書きはハッシュ行を API 境界で扱う

エディタに表示する `contents.en.md` の本文には原文ハッシュ行を含めてはならない（SHALL NOT）。保存（`language: "en"`）は既存ファイルのハッシュ行を保持したまま本文だけを差し替えなければならない（SHALL）——手動保存はハッシュに触らない。ファイルが無い状態での保存は、本文が空なら作成せず（SHALL NOT）、非空ならハッシュ行なしで作成する（SHALL）——手動翻訳は鮮度不明として stale 扱いになる（`translation-freshness` の規則）。本文の AI 翻訳の適用は、サーバーが計算したハッシュ行つきの完成形で保存しなければならない（SHALL）。

#### Scenario: 手動保存でハッシュが変わらない

- **WHEN** ハッシュ行を持つ `contents.en.md` を英語モードで編集して保存する
- **THEN** 本文は更新され、1行目のハッシュ行は保存前と同一である

#### Scenario: 空のまま切り替えてもファイルは生まれない

- **WHEN** `contents.en.md` が無いレッスンを英語モードで開き、何も入力せず離れる
- **THEN** `contents.en.md` は作成されない

#### Scenario: 本文翻訳の適用でハッシュ行が付く

- **WHEN** 英語モードの「本文を翻訳」を実行して結果を適用する
- **THEN** 保存された `contents.en.md` の1行目は現在の `contents.md` の原文ハッシュ行である

### Requirement: ホームの英語ビューはメタと changelog を1ボタンで翻訳する

ホームの英語ビューでは、全体メタのフィールドと changelog セクション（`changelog.en.md`）が連動して切り替わらなければならない（SHALL）。翻訳ボタンは1つとし、表記は「原文から翻訳」としなければならない（SHALL）。実行では全体メタの翻訳と changelog の追訳（英語側に無い新しいエントリの翻訳）を両方行い、結果を分けて提示しなければならない（SHALL）。changelog の追訳は既存の英訳エントリを変更してはならない（SHALL NOT）——挿入はクライアントが行い、追記のみの担保は構造で持つ。

changelog セクションのラベルは `Changelog` としなければならない（SHALL）。`Description` と `Changelog` の間に区切り線を引いてはならない（SHALL NOT）。

#### Scenario: 統合翻訳の実行

- **WHEN** ホーム英語ビューで「原文から翻訳」を実行する
- **THEN** メタフィールドが埋まり、changelog の不足エントリの英訳が追記候補として提示される

#### Scenario: 片方の失敗が巻き込まない

- **WHEN** changelog の追訳だけが失敗する
- **THEN** メタフィールドの結果は使え、changelog 側のエラーが個別に表示される

### Requirement: 鮮度状態は選択時に取得して表示する

鮮度状態は選択中のユニットについて API で取得し、選択変更・保存成功・翻訳適用の後に再取得しなければならない（SHALL）。取得はロード API と分離し、正本への書き込み副作用を持ってはならない（SHALL NOT）。取得した状態は英語ビュー本文上部の赤字1行の表示判定にのみ用いる（SHALL）。

#### Scenario: 保存後に警告が追従する

- **WHEN** 日本語モードで本文を編集して自動保存が走り、英語ビューへ切り替える
- **THEN** 赤字の「翻訳が古い可能性があります」が表示される

### Requirement: 翻訳 API は stateless で契約を注入する

翻訳 API（メタ・本文・changelog）は、AI の出力値を返すだけで正本に書き込んではならない（SHALL NOT）。モデルは**ワークスペースのモデル設定（`x-ai-model` ヘッダー → `AI_MODEL` env → 既定）に従わなければならない**（SHALL）——他の AI 機能と同じ解決経路を用い、翻訳だけ固定モデルにしてはならない（SHALL NOT）。未対応モデルが選ばれている場合は、他の AI 機能と同じエラーで拒否する（SHALL）。

プロンプトには `contracts/translation-contract.md` の全文を注入しなければならない（SHALL）。既存の英訳があるユニットでは既訳を入力に含め、「既訳を活かし必要な箇所だけ更新する」ことを指示しなければならない（SHALL）。

原文ハッシュ（本文のハッシュ行・メタの `en_source_hash`）は**サーバー側で計算**しなければならない（SHALL）——モデルに計算・生成させてはならない（SHALL NOT）。

#### Scenario: モデル設定に従う

- **WHEN** ギアメニューで Fable 5 を選んだ状態で翻訳 API を呼ぶ
- **THEN** 翻訳は Fable 5 で実行される

#### Scenario: 未対応モデルは拒否される

- **WHEN** 未対応モデルが選ばれた状態で翻訳 API を呼ぶ
- **THEN** 他の AI 機能と同じ未対応モデルのエラーが返り、翻訳は実行されない

#### Scenario: 正本に書かない

- **WHEN** 翻訳 API が成功する
- **THEN** `contents/` 配下のファイルは変更されていない

### Requirement: レッスンの本文翻訳ボタンは英語モードの本文右上に出る

レッスン本文の「原文から翻訳」ボタンは、**本文領域の右上**に置き、英語モードのときだけ表示しなければならない（SHALL）。ボタンは本文のスクロールに追従しなければならない（SHALL）。ペイン2 ヘッダーに本文翻訳のボタンを置いてはならない（SHALL NOT）——ヘッダーは `[メタ編集][3ビュー]` に限る（言語切替は GlobalHeader に移った）。エディタ本体（CodeMirror の編集領域内）に翻訳ボタンを置いてはならない（SHALL NOT）。

#### Scenario: 日本語モードでは出ない

- **WHEN** レッスンを日本語モードで表示する
- **THEN** 「原文から翻訳」ボタンは表示されない

#### Scenario: 本文右上に出る

- **WHEN** レッスンを英語モードで表示する
- **THEN** 「原文から翻訳」ボタンは本文領域の右上にあり、ヘッダーには無い

### Requirement: 翻訳ボタンの表記は「原文から翻訳」に統一する

英語ビューの翻訳を起動するボタンは、対象（メタ・本文・ホームの統合翻訳）にかかわらず**「原文から翻訳」**と表記しなければならない（SHALL）。場所ごとに異なる表記（「原文から翻訳し直す」「メタと変更履歴を翻訳」「本文を翻訳」等）を用いてはならない（SHALL NOT）。

#### Scenario: ホームの統合翻訳の表記

- **WHEN** ホームの英語ビューを表示する
- **THEN** 翻訳ボタンの表記は「原文から翻訳」である（メタと変更履歴の両方を訳す動作は変わらない）

#### Scenario: レッスン本文の表記

- **WHEN** レッスンを英語ビューで表示する
- **THEN** 本文右上の翻訳ボタンの表記は「原文から翻訳」である

### Requirement: 保存の完了はボタン上の一時的なチェックマークで示す

保存ボタンは、待機時に**保存を表すアイコン（lucide `Save`）**を表示しなければならない（SHALL）——アイコンの席が普段は空白で意味が読めない状態を作らない。保存操作が成功したことは、**同じ席のアイコンを一時的なチェックマークへ切り替えて**示さなければならない（SHALL）。表示は一定時間後に自動で `Save` アイコンへ戻る（SHALL）。アイコンの切り替えでボタンの幅が変わってはならない（SHALL NOT）——席の寸法は固定する。保存の完了を示すために本文のレイアウトを変える表示（ボタンの隣や本文末尾に増減するテキスト等）を用いてはならない（SHALL NOT）——押した場所から視線を動かさずに完了が分かることを優先する。

完了の表現は場所によって変えてはならない（SHALL NOT）——「英語版の履歴を保存しました」のような対象ごとの言い回しは用いない。

#### Scenario: 待機時に Save アイコンが見える

- **WHEN** シリーズメタビューを表示する（保存前）
- **THEN** 保存ボタンに `Save` アイコンと「保存」の表記が見える

#### Scenario: 完了でチェックマークに切り替わる

- **WHEN** 保存が成功する
- **THEN** `Save` アイコンの席が一時的にチェックマークになり、しばらくして `Save` へ戻る
- **AND** ボタンの幅は切り替えの前後で変わらない

#### Scenario: レイアウトが動かない

- **WHEN** 英語ビューで保存する
- **THEN** アイコンが切り替わるだけで、本文の高さや他要素の位置は変わらない

#### Scenario: 失敗は従来どおりエラーで示す

- **WHEN** 保存が失敗する
- **THEN** チェックマークは出ず、エラーメッセージが表示される

### Requirement: 翻訳が古いことは英語ビュー本文上部の赤字1行で伝える

英語ビューの鮮度が `stale`（翻訳が原文より古い）のとき、**本文領域の上部に赤字で「翻訳が古い可能性があります」**とだけ表示しなければならない（SHALL）。それ以外の文言・補足・操作を添えてはならない（SHALL NOT）。

この表示は英語ビューにだけ出し、日本語ビューに出してはならない（SHALL NOT）。鮮度が `untranslated` または `fresh` のときは表示してはならない（SHALL NOT）——未翻訳は英語欄が空であることで分かる。

#### Scenario: 古い翻訳の警告

- **WHEN** 日本語を編集した後で、そのユニットの英語ビューを開く
- **THEN** 本文上部に赤字で「翻訳が古い可能性があります」と表示される

#### Scenario: 日本語ビューには出ない

- **WHEN** 鮮度が `stale` のユニットを日本語ビューで表示する
- **THEN** 赤字の警告は表示されない

#### Scenario: 未翻訳では出ない

- **WHEN** 英語版がまったく無いユニットを英語ビューで開く
- **THEN** 赤字の警告は表示されず、英語の入力欄が空で表示される

### Requirement: レッスンメタの英語モーダルは日本語モーダルと同じ配置にする

レッスンメタのモーダルは、日本語・英語のどちらでも**右下に `[キャンセル][保存]`** を置かなければならない（SHALL）。英語モーダルでは加えて**右上に `[原文から翻訳]`** を置く（SHALL）。英語モーダルのフォーム内部に保存ボタンを置いてはならない（SHALL NOT）——保存の入口はフッターの1つに限る。

英語モーダルの保存は、`_en` フィールドと `author_en` を**1回の保存操作**で確定しなければならない（SHALL）——利用者から見て保存が2段階になってはならない（MUST NOT）。

#### Scenario: 日英でフッターが同じ

- **WHEN** レッスンメタのモーダルを日本語・英語で開き比べる
- **THEN** どちらも右下に「キャンセル」と「保存」が同じ順で並ぶ

#### Scenario: author_en が同じ保存で確定する

- **WHEN** 英語モーダルで `name_en` と `author_en` の両方を編集して保存する
- **THEN** 1回の保存で両方が `.meta.json` に書き込まれる

### Requirement: 言語切替は Studio ヘッダーに1つ置く

言語切替は GlobalHeader の右側、「DXトレーニング曼陀羅」ボタンの**左**に、テキスト併記のボタンとして**1つだけ**置かなければならない（SHALL）。表記は日本語ビュー時「**英語ビューに切り替える**」・英語ビュー時「**日本語ビューに戻る**」とする（SHALL）。ツールチップを付けてはならない（SHALL NOT）——ヘッダーの他メニューにツールチップは無く、そこだけ挙動が違うと浮く。狭幅時のテキスト省略は隣接ボタンと同じ作法（アイコンのみ）に従う（SHALL）。

ペイン2 の4面（ホーム・シリーズ・コース・レッスン）のヘッダーに言語切替を置いてはならない（SHALL NOT）。ツリーの行には翻訳状態を表示してはならない（SHALL NOT）。鮮度を示すチップ（「未翻訳」「英語版が古い」）をヘッダーに表示してはならない（SHALL NOT）——翻訳が古いことは英語ビュー本文上部の赤字1行で伝える。

#### Scenario: ヘッダーで切り替える

- **WHEN** GlobalHeader の「英語ビューに切り替える」を押す
- **THEN** ボタンの表記が「日本語ビューに戻る」に変わり、ペイン2 が英語ビューになる

#### Scenario: ペイン2 のヘッダーに言語切替が無い

- **WHEN** ホーム・シリーズ・コース・レッスンを順に選択する
- **THEN** どのペイン2 ヘッダーにも言語切替アイコンは無い

#### Scenario: ツールチップが出ない

- **WHEN** 言語切替ボタンにマウスホバーする
- **THEN** ツールチップは表示されない

### Requirement: 英語モードではコンテンツの名前を英語で表示する

英語モードでは、**コンテンツの名前を表示する場所**——ペイン1 ツリーの行・Studio 内曼陀羅（全体モーダル・ミニ）のノードとシリーズ枠・GlobalHeader のパンくず・ペイン2 ヘッダーのタイトル——で `name_en` を表示しなければならない（SHALL）。`name_en` が未設定（空・空白のみ）のユニットは日本語名で表示しなければならない（SHALL）——名前が空欄になってナビゲーションが壊れる状態を作らない（公開サイトと同じフォールバック規則）。

表示名の解決（`en` なら `name_en` → 日本語名）は1つのヘルパー関数に集約しなければならない（SHALL）——フォールバック規則を表示箇所ごとに複製してはならない（SHALL NOT）。

**UI 文言（ボタン・見出し・ダイアログ・エラーメッセージ）は言語モードによらず日本語のまま**としなければならない（SHALL）——英語になるのはコンテンツ由来の名前と、その名前に隣接する識別ラベル（ペイン2 バッジ）だけである。UI 文言を表示名ヘルパーに通してはならない（SHALL NOT）。

#### Scenario: ツリーが英語名になる

- **WHEN** 英語モードで `name_en` を持つシリーズ・コース・レッスンをツリーに表示する
- **THEN** 行の表示名は `name_en` になる

#### Scenario: 未訳は日本語名のまま

- **WHEN** 英語モードで `name_en` が未設定のレッスンをツリーに表示する
- **THEN** 行の表示名は日本語名で、空欄にはならない

#### Scenario: 曼陀羅とパンくずも追随する

- **WHEN** 英語モードで曼陀羅モーダルを開き、コースを選択する
- **THEN** ノードのコース名・シリーズ枠・パンくずの各段が英語名（未訳は日本語名）で表示される

#### Scenario: UI 文言は日本語のまま

- **WHEN** 英語モードでワークスペースを操作する
- **THEN** 「保存」「原文から翻訳」「DXトレーニング曼陀羅」等のボタン・見出しは日本語のままである

### Requirement: 操作ボタンの置き場は面の種類で決まる

翻訳と編集の操作ボタンは、ヘッダーではなく本文側に置かなければならない（SHALL）。置き方は面の種類で決まる:

| 面 | 置き場 | スクロール追従 |
|---|---|---|
| メタ編集面（全体・シリーズ・コース） | 本文冒頭の見出し行（右側） | **しない** |
| レッスン本文（英語ビュー） | 本文領域の右上に重ねる（overlay） | する（重なっているため常時見える） |

ボタン列の並びは**左＝AI が下書きを作る操作／右＝人が正本に書く操作**とし、この順を全画面で守らなければならない（SHALL）。日本語ビューと英語ビューで配置を変えてはならない（SHALL NOT）——日本語ビューに AI 操作が無い場合は左スロットが空になるだけとする。

この規則の例外は次の2つに限る（SHALL）:

| 例外 | 配置 |
|---|---|
| レッスンメタ**モーダル** | 右下に `[キャンセル][保存]`、右上に `[原文から翻訳]` |
| レッスン本文ヘッダー | `[メタ編集][3ビュー]` は従来どおりヘッダーに残す |

#### Scenario: メタ編集面のボタンは流れる

- **WHEN** ホームのメタビューで本文を下までスクロールする
- **THEN** ボタン列は見出し行と一緒に画面外へ流れる

#### Scenario: レッスン英語ビューのボタンは残る

- **WHEN** レッスンの英語ビューで本文を下までスクロールする
- **THEN** 「原文から翻訳」は本文領域の右上に重なったまま表示され続ける

#### Scenario: 日英で配置が同じ

- **WHEN** シリーズメタビューを日本語ビューと英語ビューで見比べる
- **THEN** どちらも見出し行の右にボタン列があり、英語ビューでは保存の左隣に「原文から翻訳」が並ぶ

### Requirement: 英語モードでも3ビューを使える

レッスンの英語モードでは、日本語モードと同じ3ビュー（編集・プレビュー・差分）を使えなければならない（SHALL）。ペイン2 ヘッダーのモード切替は英語モードでも表示し、並び・見た目を日本語モードと同一にする（SHALL）。英語モードを編集ビュー固定にしてはならない（SHALL NOT）。

選択中のビューは**言語切替をまたいで保たなければならない**（SHALL）——プレビューを見ながら言語を切り替えたら、切り替え先でもプレビューが表示される。ビューと言語は独立した状態であり、言語切替を理由にビューをリセットしてはならない（SHALL NOT）。

**英語プレビュー**は `contents.en.md` の本文（原文ハッシュ行を除く）を、日本語プレビューと同じレンダリング規則（GFM・アラート・画像・確認問題）で描画しなければならない（SHALL）。

**英語差分**は `contents.en.md` の git HEAD に対する差分を表示しなければならない（SHALL）——翻訳の採否は人が差分で行うため、Studio 内で訳文の差分が読めることを優先する。HEAD に無いファイル（初回翻訳）は全文追加として表示する（SHALL）。未訳（ファイル不在）では「差分なし」を表示し、エラーにしない（SHALL）。

#### Scenario: 英語モードにモード切替が出る

- **WHEN** レッスンを英語モードで表示する
- **THEN** ペイン2 ヘッダーに編集・プレビュー・差分の切替が日本語モードと同じ見た目で表示される

#### Scenario: ビューが言語をまたいで保たれる

- **WHEN** 日本語モードでプレビューを表示したまま英語モードへ切り替える
- **THEN** 英語のプレビューが表示され、編集ビューには戻らない

#### Scenario: 英語差分は訳文の差分を出す

- **WHEN** `contents.en.md` を編集した後、英語モードで差分タブを開く
- **THEN** `contents.en.md` の HEAD との unified diff が表示され、日本語本文の差分は混ざらない

#### Scenario: 初回翻訳の差分は全文追加

- **WHEN** HEAD にまだ無い `contents.en.md` を持つレッスンで英語差分を開く
- **THEN** 全文が追加行として表示される

### Requirement: 英語プレビューのラベル語彙は公開サイトと一致する

英語プレビューのメタラベル行は、公開サイトの英語ページと同じ語彙で表示しなければならない（SHALL）——状態は `open` / `in progress`（`done` は非表示）、所要時間は `N min`、受講形態は style 値そのまま（`self-study` 等）、著者ラベルは `author:`。著者の値は英語ビューでは `author_en` → `author`、日本語ビューでは `author` → `author_en` の双方向フォールバックとする（SHALL）。

日英の語彙表は Studio 側に持ち、公開サイトの実装（`mandala/lib/site-data.ts`）と食い違わないことを **parity テストで検証しなければならない**（SHALL）——アプリ間の実行時依存を張ってはならず（SHALL NOT）、突き合わせはテストに限る（鮮度判定 lib と同じ作法）。

#### Scenario: 英語プレビューのラベル行

- **WHEN** `in_progress`・15分・`self-study` のレッスンを英語モードでプレビューする
- **THEN** ラベル行に `in progress`・`15 min`・`self-study` が表示され、右端は `author:` に `author_en`（無ければ `author`）が続く

#### Scenario: 語彙のずれをテストが検出する

- **WHEN** mandala 側の状態ラベルの英語だけを変更する
- **THEN** Studio の parity テストが失敗する
