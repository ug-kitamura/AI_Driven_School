# skill-bundled-asset-inlining Specification

## Purpose

スキル同梱スクリプトによる CSS・アイコンのインライン化と、その素材の生成・保守の規約。

## Requirements

### Requirement: インライン化は同梱スクリプトで行う

CSS・アイコンのインライン化を持つスキルは、当該処理をスキル同梱スクリプト（`scripts/` 配下）として提供しなければならない（SHALL）。スクリプトは外部コマンド（npm / npx / シェル）の実行を必要としてはならない（MUST NOT）。SKILL.md は置換対象を列挙してモデルに手作業で書き換えさせる手順を持ってはならない（MUST NOT）。

インライン化は 1 回のスクリプト呼び出しで完結しなければならない（SHALL）。差し込み・不足素材の取得・再差し込みを複数のスクリプト呼び出しへ分割してはならない（MUST NOT）。

#### Scenario: 1 回の実行で完了する

- **WHEN** ユーザーがインライン化に同意し、スクリプトが実行される
- **THEN** CDN の除去・CSS の差し込み・アイコンの展開・不足分の取得がすべて完了し、追加のスクリプト実行を必要としない

#### Scenario: 手作業の置換手順が残っていない

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** 「Tailwind CDN を固有 CSS に置き換える」のような手作業の置換指示が存在しない

### Requirement: 生成物の自己完結

インライン化後の HTML は外部リソースへの依存を持ってはならない（MUST NOT）。Tailwind および Lucide の CDN 読み込みは除去されなければならず（SHALL）、`lucide.createIcons()` の呼び出しも除去されなければならない（SHALL）。

#### Scenario: ネットワーク無しで表示できる

- **WHEN** インライン化後の HTML をネットワークに接続していない環境で開く
- **THEN** スタイルとアイコンが正しく表示される

### Requirement: アイコンは inline SVG へ直接置換する

アイコンの展開は `<i data-lucide="X">` を inline `<svg>` へ直接置換する方式でなければならない（SHALL）。SVG スプライトと `<use>` 参照による方式を用いてはならない（MUST NOT）。元の要素の `class` と `style` は生成された `<svg>` へ引き継がなければならない（SHALL）。

#### Scenario: サイズ指定が引き継がれる

- **WHEN** `<i data-lucide="file-text" class="w-6 h-6" style="color:var(--gray-40)">` を展開する
- **THEN** 生成された `<svg>` は同じ `class` と `style` を持ち、既定サイズによる巨大化が起きない

### Requirement: 不足アイコンの取得と代替

スクリプトは、同梱素材に存在しないアイコン名を検出した場合、外部から取得して差し込んでよい（MAY）。取得に失敗した場合は代替アイコンへ差し替え、処理を継続しなければならない（SHALL）。取得の失敗を理由に処理を中断してはならない（MUST NOT）。取得したアイコンはスキルフォルダへ書き込んではならず（MUST NOT）、作業フォルダ配下へ保存しなければならない（SHALL）。

#### Scenario: 在庫外のアイコンを取得する

- **WHEN** 生成された HTML が同梱素材に無いアイコン名を含む
- **THEN** 当該アイコンが外部から取得されて展開され、取得件数が報告される

#### Scenario: オフラインでも完走する

- **WHEN** 外部への到達に失敗する
- **THEN** 当該アイコンは代替アイコンへ差し替えられ、代替件数が報告され、処理は最後まで進む

#### Scenario: スキルフォルダへ書き込まない

- **WHEN** アイコンの取得が成功する
- **THEN** 保存先は作業フォルダ配下であり、実行中スキルのフォルダではない

### Requirement: 処理結果の報告

スクリプトは実行結果として、取得したアイコン数・代替へ差し替えたアイコン数・同梱 CSS に存在しなかったクラスを報告しなければならない（SHALL）。

#### Scenario: 未収録クラスが列挙される

- **WHEN** 生成された HTML が同梱 CSS に含まれないクラスを使っている
- **THEN** 当該クラス名が報告に列挙される

### Requirement: 素材の生成と保守

スキル同梱の CSS サブセットとアイコン素材は、開発時のビルドによって生成されなければならない（SHALL）。ビルドは対象スキルの `references/base.html` および `references/model-answer.html` を語彙の入力としなければならない（SHALL）。ビルドスクリプトは、実行中スキルの `scripts/` 配下へ置いてはならない（MUST NOT）。

スキルは、モデルが用いる語彙を模範回答の範囲に寄せる旨と、Tailwind の任意値クラスを用いない旨を SKILL.md に記述しなければならない（SHALL）。

#### Scenario: 1 コマンドで再生成できる

- **WHEN** 開発者が safelist を更新してビルドコマンドを実行する
- **THEN** 対象スキルすべての CSS サブセットとアイコン素材が再生成される

#### Scenario: ビルドスクリプトがエージェントへ公開されない

- **WHEN** スキル実行中に `run_skill_script` で実行可能なスクリプトを列挙する
- **THEN** 開発用のビルドスクリプトは含まれない

#### Scenario: 任意値クラスの禁止が記述されている

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** アイコン・クラスを模範回答の語彙から選ぶ旨と、任意値クラスを用いない旨が記述されている
