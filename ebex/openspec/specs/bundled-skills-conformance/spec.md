# bundled-skills-conformance Specification

## Purpose

EBEX に同梱される実用スキルが満たすべき契約準拠（完走条件・後処理の可否確認・ホスト依存表記の排除）。
## Requirements
### Requirement: 同梱スキルの完走条件

EBEX に同梱される実用スキル（meeting-minutes / meeting-minutes-ebe / training-record / visual-explainer）は、成果物の生成手順を「額縁テンプレートを作業フォルダへコピーする → 変数プレースホルダーを一括置換する → 区間ごとに差し込む」の形で記述しなければならない（SHALL）。額縁テンプレートのコピーは、成果物本文の生成を開始するより前の工程として記述しなければならない（SHALL）。本文の生成を独立した先行ステップとして置き、コピーを後続ステップに置いてはならない（MUST NOT）。成果物 HTML の全文を 1 回の書込操作へ載せる手順を記述してはならない（MUST NOT）。1 回の差し込みは書込ツールのサイズ上限に収まる分量でなければならない（SHALL）。

#### Scenario: 大きな成果物でも書込が失敗しない

- **WHEN** 模範回答と同等の分量（40KB 超）の議事録 HTML を生成する
- **THEN** すべての書込操作が単体でサイズ上限内に収まり、上限超過による失敗が発生しない

#### Scenario: 全文一括の指示が残っていない

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** 「完成した HTML を保存する」のように成果物全文の書き出しを求める記述が存在しない

#### Scenario: 成果物ファイルが早い段階で現れる

- **WHEN** ユーザーが visual-explainer を実行し、本文の生成が始まる
- **THEN** その時点で額縁のコピーが済んでおり、成果物ファイルが作業フォルダの `output/` に存在する

### Requirement: 英語版も額縁から生成する

英語版の成果物を持つスキルは、額縁テンプレートの再コピーと区間ごとの断片差し込みではなく、完成済みの日本語版 HTML（`output/{YYYYMMDD}-{スラッグ}-xxx.html`）を読み込み、英訳した内容を `-eng.html` として保存する単一工程で生成しなければならない（SHALL）。

`lang` 属性を英語（`en`）へ変更する、という 1 行の指示を持たなければならない（SHALL）。この指示を除き、機械的な文字列置換の手順（置換の単位・順序等）を記述してはならない（MUST NOT）— 翻訳は AI の通常の英訳能力に委ねる。

保存先の成果物が書込ツールのサイズ上限を超えうる分量の場合、先頭から順に複数回へ分けて書き込む旨の指示を持ってよい（MAY）。この指示にツール名や具体的な文字数上限などホスト依存の記述を含めてはならない（MUST NOT）。この分割保存の指示は、翻訳の単位・順序に関する機械的な置換手順とは別のものであり、上記の禁止（機械的な置換手順を記述してはならない）の対象外とする。

#### Scenario: 完成済み日本語版から英語版を生成する

- **WHEN** ユーザーが英語版の生成に同意する
- **THEN** 完成済みの日本語版 HTML が読み込まれ、その内容を英訳した `-eng.html` が保存される

#### Scenario: 機械的な置換手順を持たない

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** 置換の単位（1 行以内等）や順序（長い文字列優先等）に関する手順が記述されていない

#### Scenario: lang 属性の変更指示のみが残る

- **WHEN** 対象スキルの SKILL.md の英語版生成手順をレビューする
- **THEN** `lang` 属性を英語へ変更する旨の指示が 1 行存在し、それ以外の機械的な置換規則は存在しない

#### Scenario: 分割保存の指示がホスト非依存である

- **WHEN** 対象スキルの SKILL.md が英語版の保存を複数回に分ける旨の指示を含む
- **THEN** その指示にツール名や具体的な文字数上限は含まれておらず、「先頭から順に複数回に分けて書き込む」のような役割語での表現に留まっている

### Requirement: 額縁の非表示テキストに日本語を置かない

英語版の成果物を持つスキルの額縁テンプレートは、画面に描画されない箇所（CSS コメント・HTML コメント等）に日本語を含めてはならない（MUST NOT）。

この制約は、英語版の残留チェックを「かな・漢字が 1 文字も残っていないこと」という例外のない条件として成立させるために必要である。例外条項を伴う残留チェックは判断を要し、軽量モデルで結果が揺れる。

#### Scenario: 額縁の CSS コメントが英語である

- **WHEN** 対象スキルの `references/base.html` をレビューする
- **THEN** `<style>` 内のコメントに日本語が含まれていない

#### Scenario: 残留チェックが例外条項を持たない

- **WHEN** 対象スキルの SKILL.md の英語版の完了確認をレビューする
- **THEN** かな・漢字の残留チェックに「ただし `<style>` を除く」のような例外条項が付いていない

### Requirement: 後処理工程の可否確認

対象スキルは、英語版生成・成果物のレビュー・CSS/アイコンのインライン化といった後処理工程に入る前に、実施するかスキップするかをユーザーへ尋ねなければならない（SHALL）。ユーザーの同意が得られた場合のみ当該工程を実行しなければならない（SHALL）。1 つのメッセージで複数の後処理をまとめて尋ねてはならない（MUST NOT）。

インライン化の確認では、処理後のファイルサイズの増加を**オンデマンドコンパイルの実測に基づく値**で示さなければならない（SHALL）。事前ビルドしたサブセットを前提とした値（例「約 100KB 増、46KB → 142KB」）を示してはならない（MUST NOT）。

#### Scenario: 英語版の可否を尋ねる

- **WHEN** 日本語版の生成が完了する
- **THEN** 英語版を作成するかスキップするかを尋ねるメッセージが出され、回答を待つ

#### Scenario: スキップ選択で残りを続行する

- **WHEN** ユーザーが後処理のスキップを選ぶ
- **THEN** 当該工程は実行されず、以降の手順が続行される

#### Scenario: インライン化の確認にサイズ増加が示される

- **WHEN** インライン化の可否を尋ねるメッセージが出される
- **THEN** オンデマンドコンパイルの実測に基づくファイルサイズの増加が示される

#### Scenario: 旧方式の値が残っていない

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** 事前ビルドを前提とした「46KB → 142KB」のようなサイズ記述が存在しない

### Requirement: ホスト依存表記の排除

対象スキルは、入出力の場所を「作業フォルダ」等の役割語で記述しなければならない（SHALL）。「カレントディレクトリ」「リポジトリルート」のようなホスト依存の表記を用いてはならない（MUST NOT）。作業フォルダ外のパスを参照する手順を記述してはならない（MUST NOT）。中間ファイル（partial 等）は作業フォルダ直下の `_work/` に置かなければならない（SHALL）。成果物を作業フォルダ内の `output/` に集める指示は許容される（MAY）。

#### Scenario: 入力ファイルの探索範囲

- **WHEN** スキルが文字起こしファイルや出席者リストを探す
- **THEN** 探索範囲は作業フォルダとして記述されており、カレントディレクトリという表記を用いない

#### Scenario: 作業フォルダ外を参照しない

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** リポジトリルート等、作業フォルダ外のパスを参照する手順が存在しない

### Requirement: コマンド実行を前提とする手順の排除

対象スキルは、シェルコマンド（PowerShell・bash 等）の実行を前提とする手順を記述してはならない（MUST NOT）。テンプレートへの画像埋め込みは、実行時の変換ではなくテンプレートへ事前に埋め込む形で解決しなければならない（SHALL）。

#### Scenario: ロゴが実行時処理なしで表示される

- **WHEN** meeting-minutes-ebe が議事録 HTML を生成する
- **THEN** ロゴは額縁に最初から埋め込まれており、画像を base64 化する手順は実行されない

#### Scenario: PowerShell 手順が残っていない

- **WHEN** 対象スキルの SKILL.md をレビューする
- **THEN** PowerShell やその他のシェルコマンドを実行する手順が存在しない

### Requirement: 完了条件としての残留チェック

対象スキルは、成果物の完成を宣言する前に、変数プレースホルダー（`{{XXX}}`）および空のままの区間が残っていないことを確認する手順を持たなければならない（SHALL）。残留がある状態を完了として報告してはならない（MUST NOT）。

英語版の成果物を持つスキルは、英語版の完成を宣言する前に、成果物にかな・漢字が 1 文字も残っていないことを確認する手順を持たなければならない（SHALL）。かな・漢字が残っている状態を完了として報告してはならない（MUST NOT）。

#### Scenario: 区間の差し込み漏れを検出する

- **WHEN** 3 つの区間のうち 1 つが空のまま完了報告へ進もうとする
- **THEN** 残留チェックにより差し込み漏れが検出され、当該区間の差し込みが行われる

#### Scenario: 額縁の訳し漏れを検出する

- **WHEN** 額縁の日本語の一部が英語へ置き換えられないまま英語版の完了報告へ進もうとする
- **THEN** 残留チェックにより日本語の残留が検出され、当該箇所の置き換えが行われる
