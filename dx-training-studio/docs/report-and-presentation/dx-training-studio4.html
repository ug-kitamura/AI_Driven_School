ここから先で、なぜ作るのか・何を作るのか・どこまで進んでいるのかを、ひとつずつ解説していきます。

解決したい課題 — なぜ作るのか

会社で新しいプロジェクトが始まり、ツール環境が Git / GitHub に切り替わりました。ここで、現場に 3 つの事情が同時に発生しています。

環境が変わった

新プロジェクトの開始にあわせて、ツール環境が Git / GitHub（ソースコードの変更履歴を管理し、チームで共有する仕組み）へ移行しました。

習熟度に幅がある

メンバーの多くはこれから Git / GitHub に慣れていく段階で、経験の度合いも人それぞれ。同じ内容を同じ速度で届けても、噛み合いません。

トレーナーの工数は有限

一人ひとりに対面で教えられれば理想ですが、教える側の時間は限られています。人手を増やす方向では解決しません。

だからこう考えた

受講者が自分のペースで独習できる
トレーニングコンテンツを作りたい

BEFORE — 対面研修だけの場合
  • 開催のたびにトレーナーの時間が必要で、回数が工数の上限で決まる
  • 説明の速度が全員一律。速い人は退屈、じっくり派は置いていかれる
  • あとで復習したくても、手元に残るのは断片的なメモだけ
教える人の時間が、そのまま学べる量の上限になる
AFTER — 独習コンテンツがある場合
  • 一度作れば何人が何回読んでも工数は増えない
  • 速い人は飛ばし、じっくり派は戻れる。進む速度を自分で決められる
  • 公開ページとして残るので、いつでも同じ内容に戻ってこられる
トレーナーは「作る」に集中し、届く量は人数で頭打ちにならない

ここが出発点

私が AI Driven School に入ったのは、この課題を解決したかったからです。卒業制作は、そのための道具そのものを作ります。

ツールの全体像 — 6 つの機能をひとつに

「独習コンテンツを作る」と言葉にすると簡単ですが、実際には企画・執筆・変換・公開といった性質の違う作業が並びます。DX Training Studio は、それらを 6 つの機能として 1 つのツールに統合します。それぞれ「何で実現するか」まで含めて見てみましょう。

1

トレーニングの企画作り

誰に、何を、どの順番で教えるのか。シリーズ・コース・レッスンの骨組みを対話しながら決めていきます。

AI スキルで実現
2

企画から草稿作り

決まった企画をもとに、レッスン本文の下書きを生成します。白紙から書き始める時間をまるごと省きます。

AI スキルで実現
3

草稿から原稿への作りこみ

下書きを人の手で磨く工程。構成・本文・画像・AI 相談を横並びで見ながら編集します。

4 ペインワークスペース
4

原稿から HTML への変換

原稿を保存すると、閲覧用の HTML ページが自動で組み上がります。手作業の変換は挟みません。

GitHub Actions で自動化
5

HTML ページの公開

社内トライアル版は GitHub Pages に、ゲーミフィケーション追加版は Vercel に公開します。

2 つの公開先を使い分け
6

ゲーミフィケーション

トロフィーやランキングなど、学習を続けたくなる仕掛け。追加を検討中の領域です。

任意課題 — 余裕があれば

「統合する」ことに意味がある

1 つひとつの作業は、既存のツールを組み合わせても実現できます。それでも 1 つに統合するのは、工程の間でファイルを持ち歩く手間と、そこで起きる取りこぼしがいちばん時間を食うからです。ツールを移らずに端から端まで通せることが、このプロジェクトの狙いです。

パイプラインを覗く — 実際の画面で見る

ここからは、実際に手が動く 3 つの場面 ── 原稿を書く画面、自動変換が走る瞬間、受講者が見るページを、画面そのもので見ていきます。

まとめ — 覚えて帰ってほしい 3 つ

01

課題は「教える時間が足りない」ではなく「届け方」

環境が Git / GitHub に変わり、習熟度に幅があり、トレーナーの工数は有限。この 3 つが同時に成り立つ以上、答えは人を増やすことではなく、自分のペースで独習できるコンテンツを用意することでした。

02

DX Training Studio は「工程の間」をなくす道具

企画・草稿は AI スキル、原稿は 4 ペインワークスペース、変換と公開は GitHub Actions。バラバラの道具を渡り歩かずに、企画から公開まで 1 本で通せることが価値の中心です。

03

合格条件は「端から端まで通ること」ひとつ

前半 3 項目は形になり、残るは変換・公開・仕上げ。ゲーミフィケーションは任意課題として切り分け、まずはパイプラインを通し切ることに集中します。

目指すのは「作品」ではなく、明日から社内で使える道具です。

この夏、企画 → 草稿 → 原稿 → HTML → 公開のパイプラインを端から端まで通し切ります。最初の受講者が最初のレッスンを自分のペースで読み終える瞬間まで、やり切ります。
