# VSCodeのインストールと初期設定

## 学習目標

前のレッスンで、Chocolateyという「欲しいソフトをまとめて申し込める窓口」の申請を済ませました。承認が下りていれば、いよいよその窓口を使う番です。このレッスンを読み終えると、Chocolatey経由で部門向けカスタマイズ版のVSCodeを導入し、フォルダを開いてファイルを編集できるようになります。

## 二通りの入れ方、迷ったらこちら

社内でVSCodeを調べると、実は入れ方が2通りあることに気づくかもしれません。「どちらを選べばいいのか」——ここで迷う人は少なくありません。

1. 社内システムからChocolateyを導入し、そこから部門向けカスタマイズ版のVSCodeを導入する（本トレーニングで案内する経路）
2. 社内システムからVSCodeを直接インストールする（本トレーニングでは案内しない経路）

どちらでも動作はします。しかし、このトレーニングでは①だけを案内します。理由は2つあります。まず、部門向けカスタマイズ版はあらかじめ基本的な設定が揃った状態で配布されているため、この先のレッスンで画面の差異に悩まされにくくなります（ただし拡張機能は種類によって自分で追加するものもあります。後述のGit Graphがその一例です）。もう1つは、Chocolateyはこの後のPython基礎シリーズでも使う窓口だという点です。すでに承認済みのChocolateyをそのまま使えば、VSCodeのために別の申請を新たに出す必要がありません。迷ったら①を選んでおけば間違いありません。

## Chocolatey から VSCode を入れる

Chocolateyがすでに導入済みであれば、作業はとても簡単です。Chocolatey のGUIから「Install」ボタンをクリックするだけで、部門向けカスタマイズ版VSCodeがインストールされます。コマンド入力は不要です。

> **社内画像**: Chocolatey の GUI で VSCode を検索し、「Install」ボタンをクリックする直前、または進行中の画面のスクリーンショット

インストールが完了すれば、それだけでこの節は終わりです。追加で何か設定を入力する必要はありません。

## 初めて開く画面にとまどわないために

VSCodeを初めて開いた人が最初に感じるのは、たいてい「機能が多すぎて、どこを見ればいいか分からない」という戸惑いです。アイコンやパネルがいくつも並んでいて、全部を一度に理解しようとすると手が止まってしまいます。

最初に見るべき場所は、実はごく一部です。画面の左端に、縦にアイコンが並んだ列があります。これを**アクティビティバー**と呼びます。今すぐ使うのは、そのアイコンの中の「エクスプローラー」と、画面中央に大きく広がる**エディタ領域**の2つだけです。他のアイコンが何をするものかは、今すぐ覚えなくてかまいません。使う場面が来たら、そのときにまた紹介します。

## フォルダを開いて、ファイルを編集する

このレッスンの合格ラインは、フォルダを開いてファイルを1つ編集できることです。次の手順を1つずつ進めてください。

1. VSCodeを開く
2. 上部の「ファイル」メニュー、またはアクティビティバーの「エクスプローラー」アイコンから、「フォルダーを開く」を選ぶ
3. 練習用に使うフォルダを選択して開く
4. エクスプローラーのパネルで、フォルダの中に何もファイルが無いことを確認する
5. エクスプローラーの新規ファイル作成のボタンから、新しいファイルを作成する（ファイル名は自由でかまいません）
6. 作成したファイルが中央のエディタ領域に開かれるので、そこに何か文字を入力する
7. `Ctrl + S` で保存する（社内で配布されるPCはWindowsのため、この操作で保存できます）

保存が終わった時点で、この節の操作は完了です。ファイルの中身が何であるかは問いません。

## この先で使う拡張機能、Git Graph

この先の学習では、Gitというバージョン管理の仕組みを使う場面が出てきます。Gitを学ぶ前に、ここで1つだけ言葉を目にしておいてください——**Git Graph**という拡張機能です。

Git Graphは、Gitでの変更の記録（この記録のことを「コミット」と呼びますが、今は名前だけ知っていれば十分です）が積み重なっていく様子を、コマンドを打たなくても目で追えるようにするための拡張機能です。今はまだGitそのものを扱っていないので、詳しい使い方——グラフの読み方や操作方法——には触れません。存在だけ覚えておいてください。

導入のおおまかな流れは、次のとおりです。VSCode左端のアクティビティバーにある拡張機能のアイコン（先ほどの図には無かった、もう1つ別のアイコンです）を開き、検索欄に「Git Graph」と入力し、見つかった拡張機能をインストールします。部門向けカスタマイズ版VSCodeであれば、社内のプロキシ設定はすでに済んだ状態で配布されているため、この検索やインストールの操作自体は特別な設定を追加しなくても通常どおり行えます。ただし、Git Graph自体は自動では入っていないので、この手順で各自インストールする必要があります。

とはいえ、今すぐインストールする必要はありません。Gitを学ぶ段階になったら、この節を思い出してもらえれば十分です。

*出典: [stepwill「VS CodeでGitを操作する方法とGit Graphの使い方」](https://stepwill.co.jp/git-vs-code-and-git-graph/)（2026年8月取得）*

## まとめ

このレッスンで持ち帰るのは、次の3つです。

1. **導入経路の選び方** — 社内システムからChocolatey経由で部門向けカスタマイズ版VSCodeを入れる経路を選ぶこと
2. **最初に見るべき場所** — アクティビティバーの「エクスプローラー」と、中央のエディタ領域だけで最初は十分なこと
3. **Git Graphの入れ方** — アクティビティバーの拡張機能のアイコンから検索してインストールできること（今すぐ入れる必要はないこと）
