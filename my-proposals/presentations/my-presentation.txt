Openspec というツールを紹介します。
    1. 解決する課題
        AI とやり取りを何度も繰り返して、ようやくうまくいったと思っても...
        そのやり取りが記録されず、後から再利用することができない。
        なぜこの仕様にしたか忘れてしまう。
        という問題があると思います。
    2. Openspec を一言でいうと
        仕様駆動開発を支援するツールです。
        AI とのやり取りを仕様として文書化し、仕様をもとに実装してくれます。
        作成した仕様は保存され、次のやり取りで参照されます。
        このサイクルを回せば回すほど、仕様が磨かれていき、アウトプットの品質が上がります。
        1サイクル回すのに時間がかかりますが、手戻りが減るため、トータルでは効率的と思います。
    3. セットアップ方法
        1. Node.js をインストール
            社内システムから NodeJS Selector をインストールする（無料）
            インストーラーが動作すると Node.js のバージョン選択画面が現れるため、v24シリーズの最新を選択します。
        2. npm install -g @fission-ai/openspec@latest を実行する
            openspec がインストールされます。
        3. 作業フォルダで `openspec init` を実行
            環境選択画面で Claude Code を選択します。
            .claude/skills/ 以下に openspec スキルが配置されます。
    4. 使い方手順
        1. Explore スキル実行（openspec-explore）
            plan モードのようにアイデアや企画を言語化します。
            この時点ではファイルは何も作りません。
        2. Proposal スキル実行（openspec-proposal）
            仕様を文書化して openspec/changes/ フォルダに配置します。
            1. proposal.md ... なぜ・何を作るかを定義
            2. design.md ... どう作るか・何がゴールかを定義
            3. spec.md ... 仕様を定義
            4. tasks.md ... やるタスクを定義
        3. Apply スキル実行（openspec-apply-change）
            仕様に基づいて実装します。
            完了したタスクは tasks.md に記録されます。
        4. Archive スキル実行（openspec-archive-change）
            openspec/archive/ フォルダに仕様を保存します。
            これまでに作成した仕様に変更分が継ぎ足されます。
    5. デモ
        next.js で作ったアプリにピンクモードを追加してみよう
    6. さいごに
        openspec のおかげで最近はほとんどプログラムを書かなくなりました。
        そのかわりに超絶優秀なメンバーを1人マネジメントしている感覚です。
        コードを書く人から何を作るか決める人に変わりました。
        openspec はちょっと使い方にクセがありますが、私はこれのおかげで大分助かっています。
        良かったら是非使ってみてください。
