# AI Driven School

## ツール一覧

### 1. [Minutes Maid（ミニッツメイド）](minutes-maid)

会議の音声文字起こしファイル（.vtt）を元に、議事録html図解を作成するツール。
議事録 `minutes ミニッツ` を作るので Minutes Maid

### 2. [Commit & Track tool（コミとら）](commit-track-tool)

GitHubのコミット履歴をAIで分析し、図解レポートをSlackに自動投稿するツール。

### 3. [DX Training Studio](dx-training-studio)

DX ツールトレーニングのコンテンツ計画・作成・編集・デプロイを支援する統合スタジオ（4ペイン UI）。

### 4. [EBEX](ebex)

プロジェクトフォルダ内のファイルを入力に AI スキルを発火し、出力を同フォルダに置く 3 ペインワークスペース（Editor + Browser + EXecution）。

### 5. [My Proposals](my-proposals)

会社向けの提案文を対話で材料から引き出し、日英・短尺・パーパス整合で出力する `my-writing-proposals` スキル置き場。
