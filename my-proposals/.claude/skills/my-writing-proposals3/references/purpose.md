# Purpose / Mission

提案文にさりげなく織り込むための、自分のチーム・部署の Purpose を置く場所。

**このファイルは各自が書き換えて育てる。** 別の部署の人がこのスキルを使うときは、下の記入欄を自分のものに差し替える。空のまま使ってもよい（対話で「スキップ」を選べば、Purpose は織り込まれない）。

織り込み方のルール → [SKILL.md](../SKILL.md) の「Purpose の織り込み」

## Purpose ステートメント

Empower every associate to be efficient

## 各項目の正本

上のステートメントを構成する個別項目は `ebex/contracts/ebe-purpose.md` にある。

普段の提案では、ステートメント1行を提案の文脈に溶かして言い換えれば足りる。特定の項目に強く結びつく提案のときだけ、正本を読んで該当項目を確認する。
