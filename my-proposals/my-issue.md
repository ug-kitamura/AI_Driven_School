# 自分専用の提案スキルを作る

## 変えたいこと
- 社内の課題を解決する３ペインワークスペースを作った
- 簡易版クロードコードのようなツール
- このツールを部に導入したい
- 導入にあたり AI ライセンスの承認をもらいたい

## 社内の課題
- 社内で便利な AI スキルをたくさん作っている
- しかし AI スキルの配布方法に頭を悩ませている
- 実行には VSCode + GitHub Copilot が必要だが導入が進んでいない
	- 理由１：社内のプロセスが非常に面倒で難しい
	- 理由２：個人ごとに申請と承認が必要
	- 理由３：月30€課金される（より多く使いたい人は月100€や月250€も選べるが、承認を得るのは難しい）
- 社内で使える AI API キー
	- ベーシックプラン（無料）では GPT 5 nano など軽量モデルが使えるしか使えず、成果物の品質が悪い
	- チームプラン（月150€ + 従量課金）を使って、Claude Sonnet や Opus を使いたい

## 提案のデメリット
- チームプランは人数や使用量によってはかえって高くつく（ユーザが少ない場合や、一人当たりの使用量が多い場合）

## 権限を持つ人
- 課長
	- ドイツ人
	- AI やテクノロジーにとても詳しいが、コストには厳しい
	- 論理的に話さないと聞き入れてもらえない
	- まず課長を説得する必要がある
- 部長
	- 日本人
	- AI の推進に積極的だが、AI やテクノロジーには疎い
	- オープンマインドで和を大切にする人柄
	- 最終的な承認の権限を持つ
