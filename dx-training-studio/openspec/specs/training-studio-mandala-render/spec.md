## Requirements
### Requirement: 曼陀羅は React Flow で描画する

Studio の全体曼陀羅とミニ曼陀羅は React Flow（`@xyflow/react`）で描画しなければならない（SHALL）。レイアウトは dagre による上から下（TB）の階層配置としなければならない（SHALL）。

Mermaid の flowchart 文字列を生成して SVG を `dangerouslySetInnerHTML` で挿入する方式を用いてはならない（MUST NOT）。生成後の SVG の DOM を書き換えて選択状態を表現してはならない（MUST NOT）。

曼陀羅のグラフは正本（`contents/` の `.meta.json` を読んだ `Series[]`）から組み立てなければならない（SHALL）。辺の導出規則は公開サイトと同一とし、シリーズ内は `courses` 配列の隣接鎖（order 辺）、シリーズ跨ぎは `cross_series_prev` / `cross_series_next`（cross 辺、相手が実在するときのみ）としなければならない（SHALL）。

React Flow は遅延境界（`next/dynamic` の `ssr: false`）越しに読み込まなければならない（SHALL）——曼陀羅を開かない限り読み込まれないこと。

#### Scenario: 全体曼陀羅が React Flow で出る

- **WHEN** ユーザーが GlobalHeader の曼陀羅ボタンを押す
- **THEN** React Flow で描かれた全体曼陀羅がモーダルに表示される

#### Scenario: 跨ぎリンクが辺になる

- **WHEN** コース A の `cross_series_next` に別シリーズのコース B が設定されている
- **THEN** 曼陀羅に A から B への辺が描かれる

#### Scenario: 相手が存在しない跨ぎリンクは辺にならない

- **WHEN** コース A の `cross_series_next` に存在しないコース ID が設定されている
- **THEN** その辺は描かれず、描画は失敗しない

### Requirement: 全体曼陀羅とミニ曼陀羅でノード種別を出し分ける

全体曼陀羅はコースを compact ノード（コース名と受講形態のみ）で描き、シリーズごとに背景の枠（シリーズ枠）を敷かなければならない（SHALL）。

ミニ曼陀羅は当該コースとその隣接（シリーズ内の前後・跨ぎの相手）だけを描かなければならない（SHALL）。ミニ曼陀羅にシリーズ枠を表示してはならない（MUST NOT）。

ミニ曼陀羅の**サムネイル**は compact ノードで描かなければならない（SHALL）。情報量の多いカードノードをサムネイルで用いてはならない（MUST NOT）——縮小率が上がって文字が読めなくなるため。

ミニ曼陀羅の**拡大モーダル**はカードノードで描かなければならない（SHALL）。

#### Scenario: サムネイルでコース名が読める

- **WHEN** ペイン2 のコースビューでミニ曼陀羅サムネイルを表示する
- **THEN** 各ノードはコース名と受講形態の 1 行で描かれ、コース名が読める

#### Scenario: ミニ曼陀羅にシリーズ枠が無い

- **WHEN** ミニ曼陀羅（サムネイル・拡大モーダルとも）を表示する
- **THEN** シリーズを囲う背景の枠は描かれない

#### Scenario: 全体曼陀羅にはシリーズ枠がある

- **WHEN** 全体曼陀羅を表示する
- **THEN** 各シリーズのコース群の背後にシリーズ枠が敷かれ、シリーズ名が読める

### Requirement: カードノードに載せる情報と並び

拡大モーダルのカードノードは、上から順に**シリーズ名**（補助テキスト）、**コース名**（主情報）、**レッスン数と合計所要時間**（補助テキスト）を表示しなければならない（SHALL）。受講形態のラベルはカードの**右端・高さ中央**に配置しなければならない（SHALL）。

カードにキャッチコピーを表示してはならない（MUST NOT）。

カードの寸法は上記の情報が収まる必要十分に留めなければならない（SHALL）。**実際のコース名で確認したうえで、余白を切り詰めた寸法にしなければならない**（SHALL）。

**カードの寸法は、レイアウトへ渡すノード寸法の定義と、カードのスタイルの実寸とで一致していなければならない**（SHALL）——dagre はノード寸法を固定値で受け取って座標を出すため、片方だけを変えると辺の接続位置がノードの縁からずれる。

#### Scenario: カードの情報の並び

- **WHEN** ミニ曼陀羅の拡大モーダルでコースのカードを表示する
- **THEN** シリーズ名・コース名・「N レッスン・約 M 分」がこの順で縦に並ぶ
- **AND** 受講形態のラベルがカード右端の高さ中央に表示される

#### Scenario: キャッチコピーは出ない

- **WHEN** キャッチコピーが設定されているコースのカードを表示する
- **THEN** カードにキャッチコピーは表示されない

#### Scenario: 寸法の定義と実寸が一致する

- **WHEN** カードノードを描画する
- **THEN** カードの実際の寸法は、レイアウト計算へ渡したノード寸法と一致する

### Requirement: 現在地は青枠とピンアイコンで示す

曼陀羅における現在地のコースは、ノードの枠色の変化（青系）と、ノードの**左外・高さ中央**に重ねたピンアイコン（`MapPin`）で示さなければならない（SHALL）。

「いまここ」等のテキストバッジで現在地を示してはならない（MUST NOT）。ピンはノードの内容としてインラインに配置してはならない（MUST NOT）——コース名の幅が縮み、省略位置が他ノードとずれるため。

#### Scenario: 現在地に枠とピンが付く

- **WHEN** あるコースを選択した状態で曼陀羅を開く
- **THEN** そのコースのノードは枠が青系に変わり、左外にピンアイコンが表示される

#### Scenario: テキストバッジを使わない

- **WHEN** 現在地のノードを表示する
- **THEN** 「いまここ」というテキストのバッジは表示されない

### Requirement: 辺は 1 種類のアニメーションする線とする

曼陀羅の辺は、シリーズ内（order）と跨ぎ（cross）を線種で区別してはならない（MUST NOT）。全ての辺を同一の見た目で、流れの向きが分かるアニメーション付きで描かなければならない（SHALL）。進む向きを示す矢印を辺の終端に付けなければならない（SHALL）。

辺に `stroke-dasharray` の種別ごとの上書きを行ってはならない（MUST NOT）。

シリーズ枠の破線は、辺とは用途が異なるため維持しなければならない（SHALL）。

**ゴーストノード（別シリーズの相手コース）の枠線に破線を用いてはならない**（MUST NOT）——1 枚の絵に破線の語彙が増えると読み取りが重くなるため。別シリーズであることは、カードノードではシリーズ名の行が、透明度の違いと併せて担う（SHALL）。

#### Scenario: 跨ぎ辺とシリーズ内辺が同じ見た目

- **WHEN** シリーズ内の辺と跨ぎの辺が同じ画面に描かれる
- **THEN** 両者の線の見た目は同一である

#### Scenario: ゴーストノードの枠は実線

- **WHEN** ミニ曼陀羅に別シリーズのコース（ゴースト）が表示される
- **THEN** そのノードの枠線は実線で描かれる
- **AND** カードノードではシリーズ名が併記される

### Requirement: ノードクリックでコースへ遷移する

曼陀羅のコースノードをクリックしたとき、そのコースを選択しなければならない（SHALL）。ミニ曼陀羅の拡大モーダルでノードをクリックして遷移したとき、モーダルは開いたまま遷移先コースのグラフに切り替わらなければならない（SHALL）。

Start / Goal の文字ノードとシリーズ枠を除き、遷移先を持たないノードにクリックによる遷移を割り当ててはならない（MUST NOT）。

「ノードをクリックするとそのコースに移動します」等の操作説明のキャプションを表示してはならない（MUST NOT）。

#### Scenario: ノードクリックで移動する

- **WHEN** ユーザーが全体曼陀羅のコースノードをクリックする
- **THEN** そのコースが選択され、ペイン2 がそのコースのビューに変わる

#### Scenario: モーダルは開いたまま切り替わる

- **WHEN** ユーザーがミニ曼陀羅の拡大モーダルで別のコースのノードをクリックする
- **THEN** モーダルは閉じず、遷移先コースを中心にしたグラフに切り替わる

#### Scenario: 操作説明のキャプションが無い

- **WHEN** 全体曼陀羅またはミニ曼陀羅の拡大モーダルを表示する
- **THEN** 「ノードをクリックするとそのコースに移動します」という文言は表示されない

### Requirement: Studio は曼陀羅描画に Mermaid を用いない

曼陀羅の描画に Mermaid を用いてはならない（MUST NOT）。曼陀羅専用の Mermaid 補助（描画の直列化・テーマ設定・サムネイル SVG の縮小・選択状態の DOM パッチ）は削除しなければならない（SHALL）。

曼陀羅以外の用途で Mermaid を使っている箇所があれば、それは残してよい（MAY）。

#### Scenario: 曼陀羅から Mermaid が消える

- **WHEN** 全体曼陀羅とミニ曼陀羅を表示する
- **THEN** Mermaid による SVG は生成されない

### Requirement: 曼陀羅キャンバスの高さは絶対長か親いっぱいかを選べる

曼陀羅コンポーネントは、キャンバスの高さの決め方として次の 2 つを提供しなければならない（SHALL）。

- **絶対長**: 呼び出し側が CSS の長さ（`720px` / `min(74vh, 720px)` など）を渡す
- **親いっぱい**: 呼び出し側が「親の高さいっぱいに広がる」ことを明示的に指定する

親いっぱいを指定したとき、曼陀羅のラッパとキャンバスは親の高さを埋めなければならない（SHALL）。ツールバー（シリーズ折りたたみ）を伴う場合も、キャンバスは残りの高さに収まり、親を溢れてはならない（MUST NOT）。

高さの指定として `100%` などのパーセントを絶対長として渡す使い方をしてはならない（MUST NOT）——ラッパの高さが確定していない場合にパーセントが解決できず、キャンバスが 0px に潰れるため。

親いっぱいを指定したときも、キャンバスには下限の高さを与えなければならない（SHALL）——ビューポートが低い環境でキャンバスが潰れないこと。

#### Scenario: サムネイルが親のセルいっぱいに描かれる

- **WHEN** ペイン2 のコースビューでミニ曼陀羅サムネイルを表示する
- **THEN** サムネイルのキャンバスは親のセルの高さいっぱいに描かれ、ノードと辺が見える

#### Scenario: サムネイルが親のセルを押し広げない

- **WHEN** グラフのノード数が多いコースでミニ曼陀羅サムネイルを表示する
- **THEN** 左列 4 項目で決まるセルの高さは変わらず、グラフはセルへ縮んで収まる

#### Scenario: ツールバーがあってもキャンバスが溢れない

- **WHEN** 全体曼陀羅をシリーズ折りたたみのツールバー付きで表示する
- **THEN** ツールバーとキャンバスの合計が親の高さに収まり、親を溢れない

### Requirement: コンテナの寸法が変わったら曼陀羅を再フィットする

曼陀羅は、キャンバスのコンテナの寸法が確定したとき・変わったときに、グラフ全体がキャンバスの中心へ収まるよう再フィットしなければならない（SHALL）。初期化時の一度きりのフィットで済ませてはならない（MUST NOT）。

ただし**ユーザーがパン・ズームを開始したあとは再フィットしてはならない**（MUST NOT）——ユーザーの操作を巻き戻すことになるため。操作を受け付けないサムネイルはこの制限の対象外とする（MAY）。

再フィットの実行はブラウザの描画フレームに載せなければならない（SHALL）——寸法の観測と同一フレーム内で viewport を変更しないこと。

#### Scenario: モーダルを開いた直後に中心へ収まる

- **WHEN** ユーザーが全体曼陀羅モーダルを開く
- **THEN** 開閉アニメーションの完了後、グラフはキャンバスの中心に収まっている

#### Scenario: ペインのリサイズに追随する

- **WHEN** ミニ曼陀羅サムネイルを表示した状態でペインの幅を変える
- **THEN** サムネイルのグラフはセルの新しい寸法に合わせて収まり直す

#### Scenario: パンしたあとは勝手に戻らない

- **WHEN** ユーザーが全体曼陀羅をパンまたはズームしたあと、ウィンドウの大きさを変える
- **THEN** グラフの表示位置は再フィットで巻き戻されない

### Requirement: モーダル内の曼陀羅の高さはダイアログのレイアウトが決める

全体曼陀羅モーダルおよびミニ曼陀羅の拡大モーダルでは、曼陀羅キャンバスの高さをダイアログのレイアウトだけで決めなければならない（SHALL）。ダイアログの高さとキャンバスの高さを別々に指定してはならない（MUST NOT）——両者が食い違ったとき、フレックスがキャンバスを縮め、フィット済みの表示がずれるため。

**ダイアログの高さは確定値でなければならない**（SHALL）。**上限（`max-height`）と下限（`min-height`）の組み合わせで与えてはならない**（MUST NOT）——高さが確定しないため、親いっぱいモードのパーセント高さが解決できず、キャンバスと React Flow のルートが 0px に潰れる。

親いっぱいモードでは、React Flow のルートがパーセント高さに依存してはならない（MUST NOT）。祖先の高さが確定していなくても実寸を得られる方法（絶対配置など）で埋めなければならない（SHALL）——高さの確定は呼び出し側の都合で変わるため、描画側がそれに依存しないこと。

#### Scenario: ダイアログが高さを決める

- **WHEN** 全体曼陀羅モーダルを開く
- **THEN** キャンバスの高さはダイアログの確定した高さから算出され、キャンバス自身が別の高さを主張しない

#### Scenario: React Flow のルートが実寸を持つ

- **WHEN** 全体曼陀羅モーダル・ミニ曼陀羅の拡大モーダル・サムネイルをそれぞれ表示する
- **THEN** いずれも React Flow のルート要素は幅・高さともに 0 より大きい
- **AND** コンソールに「The parent container needs a width and a height」（error #004）は出ない

#### Scenario: 低いビューポートでも潰れない

- **WHEN** ビューポートの高さが小さい環境で全体曼陀羅モーダルを開く
- **THEN** キャンバスは下限の高さを保ち、グラフが読める
- **AND** ダイアログはビューポートの外へはみ出さない

### Requirement: ミニ曼陀羅に中心コース自身の Start / Goal を出す

ミニ曼陀羅（サムネイル・拡大モーダルとも）は、**中心コース自身**が入口（`is_start`）または出口（`is_goal`）を宣言しているとき、Start / Goal の文字ノードを描かなければならない（SHALL）。

中心コース以外のノード（シリーズ内の前後・跨ぎの相手・ゴースト）が持つ入口・出口の宣言を拾ってはならない（MUST NOT）——ミニ曼陀羅は中心とその隣接 1 段だけを映す地図であり、2 段先の情報を混ぜないため。

#### Scenario: 入口のコースを開くと Start が出る

- **WHEN** `is_start` を宣言しているコースを選択してミニ曼陀羅を表示する
- **THEN** そのコースの手前に Start の文字ノードが辺で繋がって描かれる

#### Scenario: 隣のコースの入口宣言は拾わない

- **WHEN** 入口のコースを 1 個前に持つ（自身は `is_start` でない）コースを選択してミニ曼陀羅を表示する
- **THEN** 1 個前のコースは描かれるが、そのさらに手前の Start は描かれない

#### Scenario: 出口のコースを開くと Goal が出る

- **WHEN** `is_goal` を宣言しているコースを選択してミニ曼陀羅を表示する
- **THEN** そのコースの先に Goal の文字ノードが辺で繋がって描かれる

### Requirement: 曼陀羅の配色は公開サイトの曼陀羅に合わせる

Studio の曼陀羅の配色は、ライトテーマにおいて公開サイトの曼陀羅と同じ見た目にならなければならない（SHALL）。

キャンバスの地は、曼陀羅を「特別な箱」に見せない薄さでなければならない（SHALL）。ページやカードの地と同じ不透明色を用いてはならない（MUST NOT）。

配色はテーマごとの上書きではなく、テーマの役割トークンに対する割合として 1 本のレシピで書かなければならない（SHALL）。曼陀羅の中で固定の色値をテーマ非依存で用いてはならない（MUST NOT）——暗い地で沈む、明るい地で浮くといった破れを避けるため。

受講形態のラベルは、ライト・ダーク・ピンクのいずれのテーマでも地と字のコントラストが保たれなければならない（SHALL）。

#### Scenario: ライトでサイトと同じ地に見える

- **WHEN** ライトテーマで Studio の曼陀羅とサイトの曼陀羅を並べて見る
- **THEN** キャンバスの地・ノードの枠・受講形態ラベル・Start / Goal の色は同じに見える

#### Scenario: キャンバスが箱に見えない

- **WHEN** 白いモーダルの中で曼陀羅を表示する
- **THEN** キャンバスの領域が塗られた矩形として浮かず、地続きに見える

#### Scenario: ダークでラベルが沈まない

- **WHEN** ダークテーマで曼陀羅を表示する
- **THEN** 受講形態のラベルは地に対して読めるコントラストを保つ
