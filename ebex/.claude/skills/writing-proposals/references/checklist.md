# 提案書 品質チェックリスト

執筆後、以下を全て確認する。未達の項目は修正し、全項目を満たすまで完了としない。

## 内容

- [ ] 冒頭数行で「何の提案か」「読み手に何をしてほしいか」がわかる
- [ ] 背景・課題が読み手の状況に即して具体的に書かれている
- [ ] 提案内容が具体的で、読み手が実行イメージを持てる
- [ ] 期待効果が定量・定性の両面、または少なくとも一方で明確に示されている
- [ ] コスト・リソースが必要な場合、記載されている
- [ ] リスクとその対応策が示されている（該当する場合）
- [ ] 依頼事項・次のアクションが明確

## 文章表現

- [ ] 一文一義になっている（長すぎる文がない）
- [ ] 読み手視点（読み手のメリット）で書かれている
- [ ] 曖昧な語尾（「〜かもしれない」等）が根拠のある主張に置き換わっている
- [ ] 数字・事例による裏付けがある
- [ ] 見出し・箇条書きで要点がスキャンしやすい

## 前提との整合

- [ ] Step 1 で確認した前提（種類・読み手・制約・分量）と齟齬がない
- [ ] 指定された出力形式・分量に沿っている
