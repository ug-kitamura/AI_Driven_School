# uv セットアップ

## 学習目標

このレッスンを終えると、以下ができるようになります。

- `uv` が何のためのツールかを説明できる
- 社内手順に従って `uv` をインストールできる
- `uv` を使って仮想環境を作成できる
- `uv run` を使って仮想環境を activate せずに Python コマンドを実行できる

---

## uv とは？

`uv` は Python のパッケージマネージャーです。従来の `pip` や `venv` に比べて**非常に高速**で、パッケージのインストールや仮想環境の作成をシンプルな操作でまとめて行えます。

さらに `uv` の大きな特長のひとつが、**仮想環境を activate しなくてもコマンドを実行できる**点です。`uv run` コマンドを使うことで、activate／deactivate の手間なく作業できます。

Python 初心者の方でも、このレッスンの手順通りに進めれば `uv` を使った開発環境が整います。

---

## 事前準備：インストール申請

> **⚠ 重要：社内では個人での直接ダウンロードは不可です**
>
> `uv` のインストールには社内の承認プロセスが必要です。**申請からインストール完了まで数日かかる場合があるため、研修開始の 1 週間前には申請を出すことを推奨します。**

---

## uv のインストール

社内では以下の **2 通り** の方法でインストールできます。所属部署の IT ポリシーや既に使っている配布経路に合わせて選択してください。迷った場合は IT ヘルプデスクに問い合わせると、推奨ルートを案内してもらえます。

### 方法 1：社内配布ポータルを使う

1. 社内独自の承認システムから `uv` のインストール申請を出す
2. 承認後、社内のソフトウェア配布ポータルから `uv` をインストールする

### 方法 2：社内 Chocolatey ベースのパッケージ管理システムを使う

1. 社内ポータルから申請・承認を受ける
2. 指定された手順に従ってインストールする

> Chocolatey 経由の場合、今後のアップデートも同じ仕組みで配布されることがあります。

---

## インストールの確認

インストールが完了したら、ターミナル（コマンドプロンプト / PowerShell など）を開いて以下を実行してください。

```
uv --version
```

バージョン番号（例: `uv 0.x.x`）が表示されれば成功です。

<!-- スクリーンショット: ターミナルで `uv --version` を実行し、バージョンが表示されている画面 -->

表示されない場合は **IT ヘルプデスクへ問い合わせ**てください。

## 仮想環境の作成

`uv venv` コマンドで仮想環境を作成します。`.venv` という名前のフォルダが作られます。

### 手順

1. ターミナルで作業したいフォルダに移動します

```
cd 作業フォルダのパス
```

2. 仮想環境を作成します

```
uv venv
```

<!-- スクリーンショット: `uv venv` を実行し、`.venv` フォルダが作成された後のターミナル画面 -->

## Python コマンドを実行してみよう

### uv run を使う（推奨）

`uv` の便利なところは、仮想環境を activate しなくても **`uv run`** コマンドで直接実行できる点です。

まず Python のバージョンを確認してみましょう。

```
uv run python --version
```

Python のバージョン番号（例: `Python 3.x.x`）が表示されれば OK です。

続いて、簡単なコードを実行してみます。

```
uv run python -c "print('Hello, uv!')"
```

`Hello, uv!` と表示されれば成功です！🎉

<!-- スクリーンショット: `uv run python -c "print('Hello, uv!')"` を実行し、結果が表示されているターミナル画面 -->

> **💡 `uv run` のポイント**
>
> `uv run <コマンド>` とするだけで、`.venv` 内の Python やパッケージを使ってコマンドを実行できます。activate／deactivate の手順が不要なので、作業がシンプルになります。

---

### 補足：仮想環境を activate して使う方法

`uv run` を使わず、従来通り仮想環境を activate して使うこともできます。

**Windows の場合:**

```
.venv\Scripts\activate
```

**Mac / Linux の場合:**

```
source .venv/bin/activate
```

ターミナルの先頭に `(.venv)` と表示されれば、仮想環境が有効になっています。この状態では `python` コマンドをそのまま使えます。

```
python --version
```

作業が終わったら以下で仮想環境を無効化できます。

```
deactivate
```
