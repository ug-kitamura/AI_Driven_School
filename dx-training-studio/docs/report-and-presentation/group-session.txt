AI Driven School グループセッション
    1. はじめに
        私が卒業制作で作るのは 「DX トレーニング資料作りを圧倒的に効率化するツール」です。
        ツール名は 「DX Training Studio」 です。
    2. 解決したい課題
        会社で新しいプロジェクトが始まり、ツール環境が Git / GitHub に変わりました。
        でも、ほとんどのメンバーは Git / GitHub に慣れていなくて、理解度もバラバラです。
        一方で、トレーナーの工数は限られています。
        そこで 「受講者が自分のペースで独習できるトレーニングコンテンツを作りたい」 と考えました。
        私が AI Driven School に入ったのは、この課題を解決したかったからです。
    3. 企画の概要
        ツール概要
            以下を全て1つに統合したツールを開発します。
            1. トレーニングの企画作り
                スキルで実現
            2. 企画からトレーニングの草稿作り
                スキルで実現
            3. 草稿から原稿への作りこみ
                ４ペーンワークスペースを使用
            4. 原稿から HTML ページへの変換
                GitHub Actions で自動変換
            5. HTML ページの公開
                社内トライアル版を GitHub Pages に公開
                ゲーミフィケーション追加版を Vercel に公開
            6. ゲーミフィケーション
                トロフィーやランキング機能などの追加を検討中
        構成と対象
            本気AIドリルと同様に、シリーズ -> コース -> レッスン構成にします。
            今のところ対象とするお題は以下の通りです。
                1. Git / GitHub
                2. Python
                3. AI 基礎
        完成の定義
            企画 -> 草稿 -> 原稿 -> HTML -> 公開のパイプラインが端から端まで通ること。
            ゲーミフィケーションは任意課題とし、余裕があれば取り組むことにする。
