# publishing-site-mandala Specification

## Purpose

React Flow による曼陀羅（3階層のグラフ・ノード表現・操作）の要件を規定する。
## Requirements
### Requirement: 3階層の曼陀羅を React Flow で描画する

曼陀羅は React Flow（`@xyflow/react`）で描画しなければならない（SHALL）。データ源は正本の `.meta.json`（各階層の `order` とコースの `cross_series_prev` / `cross_series_next`）とし、曼陀羅専用のデータファイルを別に持ってはならない（SHALL NOT）。

3階層それぞれで描画する範囲は次のとおりとする（SHALL）:

- **グローバル曼陀羅**（全体トップ）: 全シリーズのコースを表示し、**各シリーズのコース群を背景の枠で囲い、枠にシリーズ名を表示する**
- **シリーズ曼陀羅**（シリーズトップ）: そのシリーズ内のコースの並びと、シリーズ跨ぎの接続。**表示中シリーズのコース群を背景の枠で囲い、枠にシリーズ名を表示する**。シリーズ外の相手コース（ゴーストノード）は枠に含めない
- **ミニ曼陀羅**（コーストップ）: 中央に当該コース、前後に隣接コース（同シリーズの前後と `cross_series_prev/next`）（枠は描かない）

レイアウトは dagre による自動配置とし、フロー方向は**3階層とも上から下（TB）**とする（SHALL）。ノード座標を正本に手書きさせてはならない（SHALL NOT）。

#### Scenario: シリーズ曼陀羅が order を反映する

- **WHEN** `order` が「概念 → 環境構築 → 基本操作」のシリーズのシリーズ曼陀羅を表示する
- **THEN** 3コースが上から下へその順で並び、順に辺で結ばれる
- **AND** 3コースが1つの背景枠に囲われ、枠にシリーズ名が表示される

#### Scenario: ミニ曼陀羅は縦に流れる

- **WHEN** `cross_series_prev` に他シリーズのコースを持つコースのミニ曼陀羅を表示する
- **THEN** 中央に当該コース、上に前のコース（跨ぎ含む）、下に次のコースだけが縦に並んで表示される

#### Scenario: グローバル曼陀羅のシリーズ枠

- **WHEN** 2シリーズを含むグローバル曼陀羅を表示する
- **THEN** 各シリーズのコース群がそれぞれ1つの背景枠に囲われ、枠にシリーズ名が表示される
- **AND** 枠はクリック対象ではなく、ノードのクリック遷移を妨げない

#### Scenario: シリーズ曼陀羅のゴーストは枠の外

- **WHEN** シリーズ跨ぎの接続を持つシリーズのシリーズ曼陀羅を表示する
- **THEN** 表示中シリーズのコース群だけが枠に囲われ、シリーズ外の相手コースのゴーストノードは枠の外に描画される

### Requirement: ノードクリックでコーストップへ遷移する

曼陀羅のすべてのコースノード（ゴーストノードを含む）は、クリック（タップ）でそのコースのトップページへ遷移しなければならない（SHALL）。この動作を他の機能（選択・ハイライト等）で置き換えてはならない（SHALL NOT）。

#### Scenario: ノードから遷移する

- **WHEN** グローバル曼陀羅で任意のコースノードをクリックする
- **THEN** そのコースのトップページへ遷移する

### Requirement: シリーズ跨ぎはゴーストノードで表す

シリーズ曼陀羅とミニ曼陀羅で、他シリーズのコースへの接続は**ゴーストノード**（半透明・破線等で当該シリーズ外と分かる見た目の相手コースノード）として描画しなければならない（SHALL）。行き先の無い矢印だけを描いてはならない（SHALL NOT）。ゴーストノードには相手コース名と所属シリーズが表示されなければならない（SHALL）。

#### Scenario: 跨ぎ先がノードとして見える

- **WHEN** `cross_series_next` に他シリーズのコース ID を持つコースを含むシリーズ曼陀羅を表示する
- **THEN** 相手コースがゴーストノードとして表示され、コース名と所属シリーズが読める
- **AND** クリックすると相手コースのトップページへ遷移する

### Requirement: ノードの情報密度は階層で変える

グローバル曼陀羅とシリーズ曼陀羅のコースノードは**コンパクト表示**（コース名と style ラベル）としなければならない（SHALL）。ミニ曼陀羅のコースノードは**リッチカード**（コース名・catch・レッスン数・合計所要時間・style ラベル）として描画しなければならない（SHALL）。すべて同一のデータから描き分けなければならない（SHALL）。

status（執筆状況）のバッジ・色ドットをノードに表示してはならない（SHALL NOT）——読者に必要なのは受講形態であり、執筆状況はレッスン一覧・レッスンページが担う。style ラベルはコースの `style` から取り（日本語: 独習 / 講義 / ハンズオン、英語: 小文字の値そのまま）、未設定のコースでは出さない。

#### Scenario: ミニ曼陀羅のリッチカード

- **WHEN** ミニ曼陀羅のコースノードを見る
- **THEN** コース名・catch・レッスン数・合計所要時間が1枚のカードに表示される

#### Scenario: グローバル・シリーズ曼陀羅はコンパクト

- **WHEN** グローバル曼陀羅とシリーズ曼陀羅で同じコースのノードを見る
- **THEN** どちらもコース名（と style ラベル）のみのコンパクトなノードで表示される

#### Scenario: style ラベルの表示

- **WHEN** `style: hands-on` のコースと style 未設定のコースをノードで見る
- **THEN** 前者には「ハンズオン」ラベルが表示され、後者にはラベルが出ない
- **AND** status 由来のバッジや色ドットはどちらにも表示されない

### Requirement: 現在地と推奨ルートの表示

ミニ曼陀羅では表示中のコースのノードを**現在地として視覚的に強調**しなければならない（SHALL）。シリーズ曼陀羅では「いまここ」等の現在地ピンを表示してはならない（SHALL NOT）——シリーズ内/外の区別はゴーストノードの描き分けが担う。

すべての辺（同一シリーズ内の順序辺・シリーズ跨ぎの辺とも）は**アニメーション付き**で描画し、**学習の進行方向を指す終端矢印**を持たなければならない（SHALL）。矢印の色は辺の色と揃える。順序辺と跨ぎ辺の区別は線種（実線 / 破線）で表す。

#### Scenario: ミニ曼陀羅の現在地

- **WHEN** コーストップのミニ曼陀羅を表示する
- **THEN** 中央の当該コースが前後のノードと区別できる強調表示になっている

#### Scenario: シリーズ曼陀羅にピンが無い

- **WHEN** シリーズ曼陀羅を表示する
- **THEN** 「いまここ」等の現在地ピンはどのノードにも表示されない

#### Scenario: 辺が進行方向の矢印を持つ

- **WHEN** 「コースA → コースB」の順序を持つ曼陀羅を表示する
- **THEN** A から B への辺の B 側の端に矢印が表示される
- **AND** 順序辺と跨ぎ辺の両方がアニメーションし、跨ぎ辺は破線で区別できる

### Requirement: 埋め込みグラフの操作設計

曼陀羅は初期状態で全ノードが視野に収まるよう表示し（fitView）、**ズーム倍率は 1 を上限**としなければならない（SHALL）——ノード数が少なくてもカードを実寸より拡大しない。キャンバスの既定の高さは、グローバル曼陀羅とシリーズ曼陀羅が 640px、ミニ曼陀羅が 580px とする（SHALL）。

**ページスクロールを奪ってはならない**（SHALL NOT）——初期状態ではグラフ上のホイール操作でズームしない。グラフをクリックした後にパン・ズーム操作を有効化してよい（MAY）。ノードのドラッグ移動と辺の編集は常に無効でなければならない（SHALL）。グローバル曼陀羅にはミニマップを表示し、**ミニマップにはコースノードの配置が視認できる形で描画されなければならない**（SHALL）——シリーズ枠はミニマップに描かない。

#### Scenario: 少数ノードでも拡大されない

- **WHEN** コースが2件だけのミニ曼陀羅を表示する
- **THEN** カードは実寸のまま表示され、キャンバスを埋めるような拡大は起きない

#### Scenario: ページスクロールが奪われない

- **WHEN** 曼陀羅の上にポインタがある状態でページをスクロールする
- **THEN** ページがスクロールし、グラフはズームしない

#### Scenario: ノードは動かせない

- **WHEN** ノードをドラッグする
- **THEN** ノードの位置は変わらない

#### Scenario: ミニマップにノードが見える

- **WHEN** グローバル曼陀羅のミニマップを見る
- **THEN** コースノードの配置が小さな矩形として視認でき、白紙にはならない
- **AND** シリーズ枠はミニマップに表示されない

### Requirement: グローバル曼陀羅のシリーズ枠は折りたためる

グローバル曼陀羅のシリーズ枠は、開閉操作で中のコースノードを折りたたみ・展開できなければならない（SHALL）。折りたたまれたシリーズはシリーズ名を持つ1ノードとして表示され、クリックでそのシリーズのトップページへ遷移できなければならない（SHALL）。既定は全展開とする（SHALL）。開閉状態はページ再訪時に保持しなくてよい（MAY）。

#### Scenario: シリーズを折りたたむ

- **WHEN** グローバル曼陀羅であるシリーズ枠の折りたたみ操作を行う
- **THEN** そのシリーズのコースノードが隠れ、シリーズ名の1ノードに集約される
- **AND** 他シリーズからの跨ぎの辺は集約ノードへ繋がる
