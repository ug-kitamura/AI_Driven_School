# 模範例（メール）

このスキルが目指す完成品。**品質水準・文体・構成・情報量・説明の深さ**をここから読み取る。

読み取るのは書きぶりであって、中身ではない。題材・数字・表・言い回しは流用しない。

> 本文中の場面と心の声は、模範例のための例示。実際の提案では、ユーザーが語った本当にあったことに必ず置き換える。

## 何が効いているか

- 件名と1行目で「何をしてほしいか」が終わっている
- 「なぜ今か」に**実際に見た場面と心の声**が1つだけ置かれ、抽象語を使わずに困りを伝えている
- 判断に使う材料（費用の比較）が表になっていて、推奨が明示されている
- 懸念を読み手に気づかれる前に自分から出し、そこに「半信半疑でした」という弱さをひと言だけ混ぜている
- 締めで最初の結論を言い換えつつ、部の Purpose を1文だけ、言葉を借りずに溶かしている

```
件名: 【提案】EBEXを2〜3名・1か月試させてください（追加費用ゼロ）

○○課長、△△部長

■ お願い
社内AIアシスタント「EBEX」を、部内2〜3名・1か月のトライアルで使わせてください。
追加費用はゼロです。

決めていただきたいことは3つあります。
・2〜3名でのトライアル導入（追加費用なし）
・トライアル後を見据えた開発の継続
・部の月次会議での紹介（10分）

■ なぜ今か
先月、別チームの方から「あのAIスキル、うちでも使いたい」と声をかけてもらいました。
うれしかったのですが、その場で返せたのは「VSCodeを入れて、Copilotの利用申請を出して、
承認を待ってください」でした。
相手の表情が固まったのが分かりました。私も内心で「これは使ってもらえないな」と思いました。
実際、あれから使い始めた人はいません。

道具はできているのに、渡す手段がない。
今いちばん詰まっているのはここです。

■ 現状
・AIスキルの実行には VSCode ＋ GitHub Copilot が必要
・Copilot は個別のセットアップと利用申請が要り、費用は1人あたり月30€から
・社内のフリーAPIライセンスは、ほぼ使われないまま残っている

EBEX はこのフリーAPIライセンスだけで動きます。
インストールも申請も要らず、開いたその日から使えます。

■ 選択肢と費用（3名で使う場合）

| 選択肢 | 導入の手間 | 月額 | 使えるモデル |
|---|---|---|---|
| VSCode + Copilot | 大（個別申請） | 90€〜（人数に比例） | Copilot標準 |
| EBEX フリー版 | 小（既存ライセンスのみ） | 0€ | GPT-5 nano |
| EBEX チーム版 | 小 | 150€＋従量（人数によらず定額） | Claude Sonnet／Opus |

→推奨：EBEX フリー版でのトライアル
費用ゼロで始められ、人数が増えたときにチーム版へ移る判断材料も同時に取れます。

■ 懸念と対策
◎ フリー版は GPT-5 nano しか使えず、成果物の品質に限界がある
正直に言うと、私も最初は「この軽さで実務に使えるのか」と半信半疑でした。
今回のトライアルで確かめたいのは品質ではなく、配って使ってもらえるかどうかです。
品質が要る作業は、チーム版の要否を判断する材料として持ち帰ります。

◎ チーム版に移ると月150€と従量課金が発生する
今回は有償版の予算承認は求めません。トライアルの結果を持って、改めて相談させてください。

◎ 少人数では部全体のニーズを拾いきれない
1か月後に、使った人と使わなかった人の両方から声を集めて共有します。

■ お願い（再掲）
・2〜3名・1か月のトライアル導入をご承認ください（追加費用なし）
・トライアル後の開発継続をお認めください
・部の月次会議で10分、紹介の時間をください

今週中にご返信いただければ、来月頭から始められます。

私たちが目指しているのは、一人ひとりが自分の手で効率を上げられる状態です。
その道具はもう手元にあります。あとは、渡せるようにするだけです。

〇〇
```
