    課題概要
        DX ツールトレーニングのコンテンツ作成を補助する 4 ペイン UI ツールの作成
        ツール名
            DX Training Studio
        提出期限
            2026.07.05 10:00 まで
        担当者
            mind チーム / 北村
    解くべき課題
        会社で新しいプロジェクトが始まりツール環境が git/GitHub に変わりました。
        しかし、ほとんどの人が git/GitHub には不慣れで理解度はバラバラ。
        多くの人にトレーニングをしなくてはならないが、教えられる人のリソースは限られている。
        受講者が自分のペースで、レベルに合った内容を、独習形式で進められるコンテンツを作成したい。
        補足
            私が AI Driven School の受講を決めた理由もこの課題を解決するためでした。
    作成したツールの概要
        本気 AI ドリルの構成を参考に、トレーニングをシリーズ -> コース -> レッスンに分解しました。
        それらを各ペインで効率よく管理しながら作成する仕組みです。
        コンテンツの企画・作成・公開までを支援するため、ツール名を DX Training **Studio** に変更しました。
        ライトテーマ
            全体画面（ライトテーマ）の画像 <ユーザが用意>
        ダークテーマ
            全体画面（ダークテーマ）の画像 <ユーザが用意>
    どのデータを、どこに、なぜ保存したか?
        DX Training Studio はローカルで動かすことを前提にしています。
        そのため、作成したコンテンツ（md）は  GitHub に登録すれば十分と考えました。
        また、細々とした設定は json 等でローカルに保存する仕組みにしました。
        特筆すべきは以下の2つです。
        1. 画像の管理
            どこに
                Vercel Blob に保存
                社内では Vercel Blob を使えないため、ローカル保存モードと切り替えられるようにした
                将来的には MS Azure Blob 導入を検討したい
            なぜ
                GitHub は大量の画像の置き場としては不適切 
                一方、コンテンツを公開することを考えると画像をローカルに置いておくわけにはいかない
        2. 社内コンテキストの管理
            どこに
                Vercel Neon に保存
                社内では Vercel Neon を使えないため、ローカル保存モードと切り替えられるようにした
                将来的には MS Azure Database 導入を検討したい
            なぜ
                社内独自のプロセスやルールをコンテンツに反映させたい
                コンテンツ作成時にキーワードで検索して、必要な情報を取り出す必要がある
    工夫したポイント
        画像作成や社内コンテキスト登録を AI が支援します。
        画像作成
            プロンプトを元に AI が画像を作ります。
            プロンプト自体もコンテンツ内容とカーソル位置から AI が判断して作成します。
            画像 <ユーザが用意>
        社内コンテキスト登録
            社内コンテキストの情報は膨大です。
            AI が必要なデータを抽出してマークダウンにまとめた上で登録する仕組みにしました。
            画像 <ユーザが用意>
    苦戦したポイント

        ものすごく大変でしたが、、、AI と自然な対話をしながらコンテンツを作れるようにしました。
        スキルの呼び出しやファイルの参照もできます。
