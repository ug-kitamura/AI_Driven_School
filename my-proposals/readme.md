# My Proposals

会社向けの提案文を、対話で材料を引き出し、**日英・短尺・パーパス整合**で出力するスキル置き場。

ベースはリポジトリ共通の `writing-proposals` を継承し、社内要件に合わせた `my-writing-proposals` スキルとしてカスタマイズしている。

## 使い方

Cursor / Claude で次のように依頼する。

- 「提案文を作って」
- 「会社向けの提案を書いて」
- 「my-writing-proposals」

材料は最初にまとめて渡してよい（例: `my-issue.md`）。埋まっている項目は聞き返さず、不足分だけ確認してから日英2版を一度に出力する。

## ディレクトリ構成

| パス | 役割 |
|------|------|
| `.claude/skills/my-writing-proposals/` | カスタムスキル本体（`SKILL.md` + references） |
| `my-issue.md` | 検証用の課題・材料メモ |
| `proposals/` | 生成した提案文 |
| `docs/` | grill-me 壁打ち記録・現状報告 |
| `openspec/` | スキル仕様（OpenSpec） |
| `writing-rule-example.md` | 文章ルールの参照例 |

## スキルの要点

- 上流（誰に出すか／相手の問い／何を言い切るか／パーパス整合）を対話で固めてから書く
- 5材料（変えたいこと・決裁者・相手の問い・根拠・文体見本）を1問ずつ、推奨案つきで確認
- 日本語版を先に作り、英語へ翻訳（各言語版 15〜20 行）
- 部のパーパスと矛盾しないか確認し、自然な接点があれば1文織り込む
