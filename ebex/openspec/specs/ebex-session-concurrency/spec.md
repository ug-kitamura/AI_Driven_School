## Requirements

### Requirement: フォルダ切替時の確認付き中断と単一アクティブストリーム

システムは一度に 1 つの Agent ストリームのみを実行しなければならない（SHALL）。ストリーミング中は全プロジェクトフォルダの入力送信を無効化しなければならない（SHALL）。ユーザーがストリーミング中に別のプロジェクトフォルダへ切り替えようとした場合、システムは確認モーダルを表示しなければならない（SHALL）。確認モーダルには、移動すると進行中の応答が中断されること、および中断はクライアント側の打ち切りであってサーバが既に書き込んだファイルは残る場合があることを明示しなければならない（SHALL）。ユーザーが承認した場合のみ切替を行い、進行中の Agent 処理を中断しなければならない（SHALL）。ユーザーが取り消した場合、切替を行わず処理を継続しなければならない（SHALL）。この結果、アクティブなストリームの所有者は常に表示中のプロジェクトフォルダと一致する（SHALL）。切替経路の確認モーダル配線は親コンポーネント側（`Workspace` / `FileTreePane`）に置き、`AgentChatPane` 内で完結させてはならない（MUST NOT）。

#### Scenario: ストリーミング中の切替は確認を挟む

- **WHEN** Agent がストリーミング中にユーザーが別のプロジェクトフォルダへ切り替えようとする
- **THEN** 中断される旨（作りかけのファイルは残る場合がある）を示す確認モーダルが表示される

#### Scenario: 承認で切替と中断が行われる

- **WHEN** 確認モーダルでユーザーが移動を承認する
- **THEN** 進行中の Agent 応答は中断され、表示は切替先フォルダのセッションに切り替わる

#### Scenario: 取り消しで切替されず継続する

- **WHEN** 確認モーダルでユーザーが取り消す
- **THEN** フォルダは切り替わらず、進行中の Agent 応答は継続する

#### Scenario: 非ストリーミング時の切替は確認なし

- **WHEN** Agent がストリーミングしていない状態でユーザーがフォルダを切り替える
- **THEN** 確認モーダルは表示されず、通常どおり即座に切り替わる

### Requirement: 中断は実行中処理を速やかに停止する

システムはユーザーによる中断（フォルダ切替の承認、または中断ボタン）を受けたとき、進行中の処理を速やかに停止しなければならない（SHALL）。中断シグナルは、実行中の LLM 呼び出し、実行中のスクリプト子プロセス、および確認待ち（ツール確認の保留）へ伝播し、それぞれを打ち切らなければならない（SHALL）。ツール逐次実行のループは、次のツールを実行する前に中断状態を確認し、中断されていれば残りのツールを実行してはならない（MUST NOT）。既存の反復・時間・出力の上限（`MAX_AGENT_LOOP_TURNS`、`GENERATE_MAX_SECTIONS`、スクリプトのタイムアウト、Node Permission Model）は本要件により変更されない。

#### Scenario: LLM 呼び出し中の中断は打ち切られる

- **WHEN** LLM への呼び出しが進行中に中断される
- **THEN** 呼び出しは abort され、ループは停止する

#### Scenario: スクリプト実行中の中断は子プロセスを止める

- **WHEN** スクリプトが実行中に中断される
- **THEN** 子プロセスは速やかに終了し、タイムアウト到達を待たずに停止する

#### Scenario: 確認待ち中の中断は即座に解決される

- **WHEN** ツール確認の保留中（ユーザー応答待ち）に中断される
- **THEN** 確認待ちは TTL の満了を待たず即座に解決（拒否相当）され、ループは停止する

#### Scenario: ツール逐次実行の合間で中断が効く

- **WHEN** 1 ターンに複数の tool_use があり、途中で中断される
- **THEN** 次のツールは実行されず、残りの tool_use は実行されない

### Requirement: 同一セッション内のツール逐次実行

1 ターンで複数の tool_use が返された場合でも、システムはそれらを逐次（1 つずつ、確認・実行・結果確定を経てから次へ）実行しなければならない（SHALL）。ツールを並行実行してはならない（MUST NOT）。

#### Scenario: 複数 tool_use は順に実行される

- **WHEN** 1 ターンに複数の tool_use が含まれる
- **THEN** それらは宣言順に 1 つずつ実行され、確認ダイアログが同時に競合しない
